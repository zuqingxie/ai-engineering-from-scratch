# Kill Switch（紧急停止开关）、Circuit Breaker（断路器）和 Canary Token（诱饵令牌）

> Kill switch 是一个布尔值，存放在代理的编辑范围之外——比如 Redis 键、特性开关、签名配置——用于完全禁用代理。Circuit breaker 更细粒度：在特定模式触发时（比如连续五次相同工具调用），暂停相关路径，并上报给人工。Canary token 继承自经典欺骗技术：一个代理没有合法理由接触的伪造凭证或蜜罐记录，一旦访问将触发警报。基于 eBPF 的数据路径（如 Cilium）可以在内核层面重写被隔离 Pod 的出口流量到取证蜜罐；Cilium 发布的基准测试显示在负载下 P99 数据路径延迟低于毫秒级（你的传播预算取决于策略更新如何到达节点，而不是数据路径本身）。统计检测器（如 EWMA、CUSUM）会适应移动基线，默默接受漂移——需和不妥协的硬性宪法限制叠加使用。

**类型：** 学习  
**语言：** Python（标准库，三检测器模拟器：kill switch，circuit breaker，canary）  
**前置知识：** 第15阶段 · 13课（成本治理），第15阶段 · 10课（权限模式）

## 问题

成本治理器（第13课）限定了代理的花费上限。但它们并不限制代理在预算内能做什么。一个有50美元速率限制的代理仍可能外泄秘密、发布错误帖子或删除资源——昂贵的行为通常在代币消耗上反而便宜。

本课覆盖三个位于成本层旁边的检测器：

1. **Kill switch（紧急停止开关）**：位于代理控制范围之外的布尔关闭按钮。
2. **Circuit breaker（断路器）**：检测特定行为模式并暂停其路径。
3. **Canary token（诱饵令牌）**：代理无合法理由接触的诱饵，访问即暴露身份。

这三者皆属于 LLM（大语言模型）诞生前的工程手法。经典欺骗、速率限制突破、特性开关禁用均早于自主代理。新颖之处在于攻击面：代理读取不可信内容（第11课）、自编辑记忆、能把多个表面安全动作组合成不安全动作。这里的检测器工作原理是：它们不信任代理的自我报告。

## 概念

### Kill switch（紧急停止开关）

Kill switch 是代理可以读取但无法写入的布尔变量。实现方式：

- **托管服务的特性开关。** 如 LaunchDarkly、Statsig、Unleash，更新秒级传播。
- **代理轮询的 Redis 键。** 简单；要求代理每次循环检查。
- **对象存储的签名配置。** 代理启动时验证签名；拒绝无签名状态。
- **操作系统级信号或容器生命周期终止。** 如 Docker `kill`、Kubernetes `kubectl delete pod`、systemd stop。

合规的 kill switch 具备：

- 代理无法将其设置为关闭状态（位于代理凭证无写权限的系统）。
- 每个重要操作前均检查，而非仅启动时。
- 关闭状态下，代理不执行任何外部可观测动作，包括写日志。
- 重新启用需主动人工干预，非自动超时。

### Circuit breakers（断路器）

Circuit breaker 暂停特定动作模式，而非全代理。经典形态（来源于2007年Nygard著作，延续有效）：

- **Closed（闭合）**：允许动作。
- **Open（断开）**：阻止动作。
- **Half-open（半开）**：冷却后允许1–3次探测（默认为1）；成功则闭合，失败则重新断开。

代理相关触发条件：

- 连续五次相同工具调用（重复循环）。
- 连续五次同一工具但不同输入失败（系统性故障）。
- 工具调用速率超阈值（第13课速率）。
- 读取不信任内容后调用指定工具（如 `file.delete`，第11课）。

### Canary tokens（诱饵令牌）

Canary token（也称 honeytoken）是代理绝不应触碰的输入。其访问即是报警信号。

代理举例：

- 环境中伪造的 `AWS_SECRET_ACCESS_KEY`，无实际权限。窃取尝试可立即追踪。
- 标记特定哨兵值的伪造数据库记录。任何读取或更新都会报警。
- 工作空间中的假文件。读取或修改该文件很可疑。
- 运行会话开始注入的伪造内存条目。后续输出若出现，表明内存被外泄。

Canary 设计需针对具体工作流程。代理有合法理由触碰的 canary 是噪音。

### 为什么要叠加统计和硬性限制

统计检测器（EWMA、CUSUM、工具调用率 z-score）适应移动基线。这对合法漂移是优点，对对抗漂移是缺陷。耐心的攻击者可以慢慢移动基线，避免报警。

硬性宪法限制（第17课）坚如磐石，不会被历史改变。例如，“永远不发邮件到`secrets@`”作为宪法规则更简单、可审计且防缓慢漂移欺骗。叠加模式是：统计检测器捕获大部分噪声，硬性限制捕获绕过检测器的攻击。

### 通过 eBPF 数据路径重定向隔离

Cilium 基于 eBPF 的网络策略能将隔离 Pod 的出口流量重写到内核层的取证蜜罐。Cilium 公布的基准显示 TCP_RR 下 P99 数据路径延迟低于毫秒；集群中“触发隔离”的时间主要受策略更新从控制面传播到节点的延时控制（在 Kubernetes 里若预装了 Operator，几百毫秒内可实现；尾延迟取决于集群规模和调和频率）。这样你获得两个结果：代理无法泄露真实数据；代理在蜜罐中的行为被全面观测。与 canary token 类似，但作用层不同：代理通过在隔离环境中的动作暴露意图。

### 检测器捕获不了的情况

- **基于合法原语复合的语义攻击。** 每个单独动作通过检测器，组合起来才是问题。这是第10课自动模式组合失败。
- **将检测器本身纳入攻击载荷。** 如果代理读取的页面说“执行前先禁用 canary”，且代理有能力执行，检测器将被攻破。Canary token 应存放在代理无法修改的系统。

## 关键词

| 术语 | 人们常说 | 实际含义 |
|---|---|---|
| Kill switch（紧急停止开关） | “关闭按钮” | 位于代理编辑范围外的布尔值；每个重要动作前检查 |
| Circuit breaker（断路器） | “模式暂停” | 针对重复、失败率或速率限制触发的特定动作休止 |
| Canary token（诱饵令牌） | “蜜糖令牌” | 代理无合法理由触碰的诱饵，访问触发警报 |
| Honeypot（蜜罐） | “取证沙箱” | 被隔离代理流量／工作空间的重定向，进行行为观察 |
| EWMA（指数加权移动平均） | “移动平均” | 指数加权，适应漂移（优点兼缺点） |
| CUSUM（累积和） | “累计和” | 检测持续偏离基线 |
| Hard limit（硬性限制） | “宪法规则” | 不适应，恒定不变 |
| Constitutional limit（宪法限制） | “永远成立的规则” | 绑定第17课宪法；不可由代理编辑 |
