# LLaVA-OneVision：单图、多图、视频一体模型

> 在 LLaVA-OneVision（Li 等，2024 年 8 月）之前，开源视觉语言模型（open-VLM）领域存在分支：LLaVA-1.5 针对单图，多图模型如 Mantis 和 VILA，视频模型如 Video-LLaVA 和 Video-LLaMA。每个模型在其基准测试中表现优异，但在其他场景表现不佳。LLaVA-OneVision 提出，一个统一的训练课程可以训练一个模型主导三种场景，并且任务间的迁移效应（单图技能迁移到视频，多图推理迁移到单图）能超越各专才模型的总和。其做法看似简单：保持视觉 token（visual-token）预算在所有场景中不变，并使用显式的课程从单图训练到 OneVision（多图）再到视频。本课解析预算、课程设计和新兴行为。

**类型:** 构建  
**语言:** Python（标准库，token 预算求解器 + 课程规划器）  
**先决条件:** 第 12 阶段 · 05（LLaVA），第 12 阶段 · 06（任意分辨率）  
**时间:** ~180 分钟

## 学习目标

- 设计一个在单图、多图和视频输入间保持恒定的视觉 token 预算。
- 排列训练课程，实现场景间的技能迁移，避免灾难性遗忘（catastrophic forgetting）。
- 解释为何单一模型在正确课程设计下，能在相同参数量上超越专才模型。
- 说出 LLaVA-OneVision 报告的三项新兴能力：多摄像机推理、标记集合提示（set-of-mark prompting）、iPhone 截屏代理。

## 问题背景

图像、多图和视频对模型的需求不同。

- 单图：需要高分辨率 tokens（AnyRes，大约 2880 视觉 tokens），以捕捉 OCR 和精细细节。每样本预算：1 张图，2880 tokens。
- 多图：需要多张中等分辨率图像（每张约 576 tokens），以便跨图推理在上下文中容纳。每样本预算：4-8 张图，每张 576 tokens，合计 2300-4600 tokens。
- 视频：需求多帧低分辨率（每帧池化后约 196 tokens）以捕获时序动态。每样本预算：8-32 帧，每帧 196 tokens，合计 1600-6200 tokens。

若训练独立模型，则只用一种预算；若训练单模型，则需预算在不同场景间合理缩放，避免超出上下文长度。

OneVision 之前通用答案是“训练一个场景，忽略其他”。Video-LLaVA 通过额外训练阶段后兼顾视频；LLaVA-NeXT 以平铺方式支持多图。均未实现三场景的优雅统一。

## 概念解析

### OneVision token 预算

LLaVA-OneVision 选用统一视觉 token 预算，大约为每样本 3000-4000 tokens，不同场景分配如下：

- 单图：AnyRes-9（3x3 瓦片 + 缩略图），每瓦片分辨率为 384，包含 729 个 patch，经过 2x2 双线性池化降至 182 tokens/瓦片。总计：9 * 182 + 182 = 1820 tokens。或 AnyRes-4，单瓦片 729 tokens，总计 2916 + 729。
- 多图：每图中等分辨率（384，不平铺），729 tokens，无池化。预算 6 张图，共计 4374 tokens。
- 视频：32 帧，分辨率 384，强池化 3x3 双线性，单帧为 81 tokens。总计：32 * 81 = 2592 tokens。

此分配保证总视觉 token 数大致稳定。LLM（大语言模型）从未遭遇超出上下文限制的批量输入。编码器每场景输出不同几何形状，但 LLM 消费的 token 总数不变。

### 三阶段课程设计

LLaVA-OneVision 训练分三阶段：

1. 单图微调（stage SI）。所有数据均为单图 + 文本，使用高分辨率 AnyRes 输入。训练目标为感知、OCR、细粒度理解。数据集使用 LLaVA-NeXT 加 OneVision 专属单图数据。
2. OneVision 微调（stage OV）。混合单图、多图与视频（帧均匀采样），用统一 token 预算训练。培养模型处理异构批次输入形状。不重置权重，基于 SI 阶段继续训练。
3. 任务迁移（stage TT）。根据目标任务比例调整训练，通常多图或视频为主。可选部署微调。

重点：课程顺序至关重要。视频优先或多图优先训练导致单图表现下降，即使数据相同。论文进行了显式消融分析。

### 为什么课程有效

单图训练构建感知基础。patch tokens 携带细粒度视觉特征，LLM 学习将其与文本融合。多图和视频引入结构性挑战（图像标签、时间先后）——无稳固感知基础难以学习。

若从头同时训练所有场景，模型将感知不足（单图数据在批次中比例低）且结构过拟合（多图/视频数据占比高），导致模型对视觉信息浅显，对跨图推理反而过度拟合。

课程顺序确保先建感知能力（SI 阶段），后学组合与时序推理（OV 阶段），保持两者均衡。

### 新兴的跨场景技能

LLaVA-OneVision 报告三项新兴能力：

1. 多摄像机推理。训练时分别使用多图和视频，推理时处理多摄像机驾驶场景。模型正确整合视角，尽管训练中未涉及该格式。
2. 标记集合提示（set-of-mark prompting）。用户在图像上用编号标记对象，模型推理“标记 3 相对于标记 7 的动作”。未明确训练标记或标注，能力源自空间定位与多图参照的组合。
3. iPhone 截屏代理。用户提供 iPhone 截屏，询问下一步点击计划。训练数据包括 UI 截屏、用户工作流程视频和多图前后对。能泛化到实际代理使用。

这些非训练任务，纯粹从课程组合结构中自发出现。

### 视觉 token 池化

token 预算要求对视觉 tokens 进行池化。OneVision 采用 2D patch 网格上的双线性插值：例如 24x24=576 patches 降至 12x12=144（2 倍池化）或 8x8=64（3 倍池化）。池化在 patch-grid（补丁网格）空间进行，而非 token 空间，以保留局部一致性。

各场景的池化因子是超参数。池化少则 token 多，表示更丰富；池化多则 token 少，能放入更多帧/图像。

### LLaVA-OneVision-1.5

2025 跟进版本（LLaVA-OneVision-1.5，arXiv 2509.23661）实现训练数据、模型权重和代码完全开源。性能与专有版本在部分基准持平，普及了该方案。使用相同课程，更多数据，改进基础 LLM。架构无变化。

### 与 Qwen2.5-VL 的对比

Qwen2.5-VL（第 12.09 课）做出不同选择。它使用 M-RoPE 和动态图像帧率（dynamic FPS），而非固定池化。其预算随输入长度变化——1 分钟视频使用的 token 比 5 秒视频多。LLaVA-OneVision 固定预算，通过池化因子调节。两者皆可行，权衡了可配置性与预测性。

## 使用方法

`code/main.py` 是一个针对 OneVision 风格视觉语言模型的课程和预算规划器。给定每样本 token 预算与目标场景比例（例如 40% 单图，30% 多图，30% 视频），它会：

- 分配分辨率、池化因子和每场景帧数。
- 检查所有场景是否均在共享预算内。
- 报告预期 token 数、LLM FLOPs 及 token 不足的场景。
- 打印分阶段训练计划。

可用其规划 OneVision 微调，或验证 VLM 部署时的单请求成本合理性。

本课产出文件为 `outputs/skill-onevision-budget-planner.md`。给定目标任务分布和每样本预算，该文件给出 AnyRes 参数、单帧池化参数、视频帧数以及课程阶段权重。每次训练或微调统一场景 VLM 时请使用。

## 练习题

1. 你的产品支持 80% 单图，10% 多图（2-4 图），10% 视频（8-16 帧）。设计 token 预算。你会如何利用多图节省下的预算？

2. 阅读 LLaVA-OneVision 第 4.3 节（新兴能力）。提出第四个课程可能激发却未在论文中报告的新兴技能。

3. 交换课程顺序——先训练多图，再单图，最后视频。预测哪些基准会下降，并解释原因。

4. 论文中视频基准训练仅用 8 帧。该训练是否能泛化到推理阶段的 30 秒视频？首先被打破的是 token 预算还是时序推理能力？

5. 24x24 patch 双线性池化至 12x12 是每维度 4 倍降低。用标准库 Python 实现池化，并验证每个 2x2 块的均值是否匹配双线性插值输出。

## 关键词汇

| 术语 | 口语描述 | 实际含义 |
|------|--------------|-----------------------|
| OneVision 场景 | “单图、多图或视频” | 统一 VLM 处理的三种输入形态之一；预算在其间保持恒定 |
| Token 预算 | “每样本多少 tokens” | LLM 训练/推理时视觉 token 的总数，通常在 3000-4000 范围 |
| 课程（Curriculum） | “训练顺序” | 按阶段顺序（单图→多图→视频）的训练方案，促进能力迁移 |
| 双线性池化（Bilinear pooling） | “token 缩减” | 对补丁网格（二维）进行双线性插值以降低 token 数，同时保持局部特征 |
| 新兴技能（Emergent skill） | “未训练却有效” | 训练中无该任务，却因课程组合而在推理时出现的能力 |
| AnyRes-k | “k 瓦片布局” | k 个固定分辨率子瓦片加一个缩略图，常用 k ∈ {4,9} |
| 任务迁移（Task transfer） | “跨场景泛化” | 单图上学到的技能通过共享骨干网络应用于视频及其他场景 |
