# 具身视觉语言行动模型（Embodied VLAs）：RT-2、OpenVLA、π0、GR00T

> 第一次让模型从网站上读取食谱并在厨房机器人中执行的是RT-2（Google DeepMind，2023年7月）。RT-2将动作离散化为文本令牌，联合微调了基于网络数据和机器人动作数据的视觉语言模型（VLM），证明了网络规模的视觉语言知识能够迁移到机器人控制。OpenVLA（2024年6月）提供了开源7B参考模型。Physical Intelligence的π0系列（2024-2025年）引入了流匹配（flow-matching）动作专家。NVIDIA的GR00T N1（2025年3月）实现了面向类人机器人的双系统（系统1 / 系统2）控制。视觉语言行动（VLA）原语——一个兼具视觉、语言理解和动作执行的单一模型——是本阶段理解模型与第15阶段自主系统之间的桥梁。

**类型：** 学习  
**语言：** Python（标准库，动作令牌器 + VLA推理骨架）  
**先决条件：** 第12阶段·05（LLaVA），第15阶段（自主系统，参考）  
**时间：** 约180分钟

## 学习目标

- 描述动作令牌化（Action tokenization）方法：离散箱编码（RT-2）、FAST高效动作令牌、连续流匹配动作（π0）。
- 解释为什么在网络数据和机器人数据上联合微调能够保持通用知识向新任务的迁移能力。
- 比较OpenVLA（开放7B Llama+VLM）、π0（流匹配）和GR00T N1（双系统）在同一个机器人任务上的表现。
- 说明Open X-Embodiment数据集的名称及其作为RT-X训练语料的作用。

## 问题背景

从自然语言指令执行家务机器人的研究目标自1970年代以来一直存在。2020年代的答案是视觉语言行动（VLA）模型。其采用与视觉问答（VQA）相同的视觉语言模型架构，但输出的是动作（关节力矩、末端执行器姿态、离散命令）而非文本。

VLA特有的挑战：

1. 动作空间连续（关节角度、力）且高维（7自由度机械臂 + 3自由度夹持器 = 10维，30 Hz 控制频率）。
2. 特定机器人训练数据稀缺。Open X-Embodiment约有100万条轨迹，网络图文数据超过50亿条。
3. 控制频率关键。30 Hz循环意味着每一步动作只有33毫秒预算。
4. 安全性。错误动作可能损坏硬件、人身或财产。

## 概念介绍

### 动作令牌化（Action tokenization）（RT-2）

RT-2的技巧是将每个关节目标表示为量化的文本令牌。将归一化的[-1, 1]区间离散为256个箱子（bins），每个箱子映射到一个词汇表ID。10自由度动作在每个控制步骤变为10个令牌。

联合微调PaLM-X视觉语言模型：

- 网络图文对（图像描述、视觉问答）
- 机器人示范，动作以令牌形式表示

模型接收“拿起红色方块”（语言）→ 图像（视觉）→ 10令牌动作序列（离散化关节目标）。网络预训练保持了通用知识迁移：RT-2能执行“移动到快速移动的物体”这类没在训练中出现的表达。

RT-2论文中推理频率3-5 Hz，受限于VLM自回归解码。

### OpenVLA — 开源7B参考模型

OpenVLA（Kim等，2024年6月）是开源权重的RT-2等价物。采用7B Llama骨干，DINOv2 + SigLIP双视觉编码器，行动令牌化覆盖256个箱子。

在Open X-Embodiment（跨22机器人970k轨迹）上训练。支持LoRA微调以适应新机器人。

推理速度：A100上4-5 Hz（量化）。足够慢速操作，不适合高频控制。

### FAST令牌器 — 更快动作解码

Pertsch等（2024）指出离散箱令牌化效率低——大部分动作集中于箱空间的小区域。FAST（频域动作序列令牌器）通过离散余弦变换（DCT）压缩动作序列，并量化变换系数。

一条30步轨迹压缩成约10个FAST令牌，而非300个离散箱令牌。推理速度提升3-5倍且质量无损。

### π0和流匹配动作

Physical Intelligence的π0（Black等，2024年10月）用流匹配动作专家替换了离散动作令牌：

- 小型动作Transformer读取VLM隐状态，输出连续的50步动作序列，通过整流流（rectified flow）生成。
- 动作头采用流匹配损失训练，VLM预训练保持不变。
- 推理时通过约5步去噪产生完整动作序列，相当于50 Hz控制频率。

π0宣称在多样操纵任务中超越OpenVLA和Octo。连续动作建模保持了离散化破坏的平滑性。

π0.5和π0-FAST是渐进式升级，后者结合了FAST令牌化与流匹配。

### GR00T N1 — 类人双系统控制

NVIDIA的GR00T N1（2025年3月）面向关节自由度超过30的类人机器人（全身）：

- 系统2：大型VLM读取场景和指令，约1 Hz生成高阶子目标。
- 系统1：小型动作头Transformer以50-100 Hz频率在子目标条件下生成低阶关节命令。

这种划分对应Kahneman的快速-慢速思维：系统2负责规划，系统1负责执行。优点是慢速大型模型规划不阻塞快速控制，系统1保持小巧低延迟。

GR00T N1.7（2025年底）加强数据扩展。GR00T使用Omniverse的仿真到现实（sim-to-real）数据进行微调。

### Open X-Embodiment

训练数据集。RT-X（2023年10月）整合了22个数据集，覆盖22款机器人100万条轨迹。Open X-Embodiment是通用训练语料库：

- 包含ALOHA、Bridge V2、Droid、RT-2 Kitchen、Language Table等数据集。
- 每条样本格式为（机器人状态，摄像头视图，指令，动作序列）。
- 训练规范：统一动作空间，归一化关节范围，摄像头尺寸调整。

OpenVLA和π0基于Open X-Embodiment训练。通过LoRA微调100-1000条专用示范，实现与特定机器人的领域差距弥合。

### 联合微调与纯机器人训练

联合微调将网络视觉问答数据与机器人轨迹混合训练。比例重要：过多问答数据导致忘记动作，过多机器人数据则丧失通用知识。

RT-2的比例约1:1，OpenVLA约0.5:1（网文:机器人），π0类似。精确比例是随数据集大小调整的超参数。

纯机器人训练生成专用模型，难以应对分布外指令。联合微调是“拿起红方块（示范）”与“拿起从左起第三大物体（新表述）”间的关键差异。

### 安全与动作限制

所有生产VLA均具备：

- 硬性关节限制（不能超过扭矩规范）
- 速度限制（软限制裁剪）
- 工作空间边界（末端执行器不能离开桌面）
- 新任务需人工审批

这些限制位于VLA之外作为控制层校验。VLA输出为建议，而非最终命令。

## 实践操作

`code/main.py`：

- 实现256箱动作令牌编码与解码。
- 草拟基于DCT+量化的FAST令牌器。
- 比较（离散箱，FAST，连续流）在每步动作令牌数上的差异。
- 打印RT-2 → OpenVLA → π0 → GR00T的世系总结。

本课程产出`outputs/skill-vla-action-format-picker.md`。根据机器人任务（操纵、导航、类人全身）选择相应动作格式：离散箱+RT-2，FAST+OpenVLA，流匹配+π0，或双系统+GR00T。

## 练习题

1. 一个10自由度手臂控制频率30 Hz，256箱离散令牌化每秒产生多少令牌？7B VLM能跟上吗？

2. FAST令牌化将30步轨迹压缩至约10令牌，如果轨迹有高频动作（如打鼓），用户会失去什么？

3. π0的流匹配头约5步去噪完成推理，跟OpenVLA的4-5 Hz自回归解码相比吞吐率如何？

4. GR00T的系统1/系统2划分对应Kahneman。设计一个可能辅助双足行走的不同划分（系统3？）。

5. 阅读Open X-Embodiment第4节关于数据集策划，列举防止领域泄漏的三条策划规则。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| VLA | “视觉语言行动” | 输入图像+指令，输出动作命令的模型 |
| 动作令牌化 | “离散箱” | 将连续关节指标量化到256个箱，每箱对应词汇ID |
| FAST令牌器 | “频域动作令牌” | 使用DCT+量化压缩30步轨迹至约10令牌 |
| 联合微调 | “混合网文和机器人数据” | 同时在网络视觉问答和机器人示范上训练，保持通用知识 |
| 流匹配动作头 | “π0连续输出” | 小型Transformer通过整流流输出50步动作序列 |
| 系统1 / 系统2 | “双系统控制” | 大型VLM慢速规划，小动作头快速执行；GR00T模式 |
| Open X-Embodiment | “RT-X数据集” | 跨机器人百万轨迹数据集；通用训练语料 |
