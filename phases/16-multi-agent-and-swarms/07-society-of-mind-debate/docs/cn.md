# Society of Mind 与多代理辩论

> 明斯基（Minsky）1986年的前提——智能是专家的社会——每十年都会被重新发现。2023年，Du 等人将其转化为具体算法：多个大型语言模型（Large Language Model，LLM）实例提出答案，阅读彼此的回答，批判并更新。经过 N 轮，他们达成共识，优于零-shot 代码推理（Chain of Thought，CoT）和反思，在六个推理和事实性任务上表现更好。有两点发现很重要：**多个代理**和**多轮**各自独立贡献。社会智能优于单代理独白；多轮交流优于一次性投票。

**类型：** 学习 + 构建  
**语言：** Python（标准库）  
**先决条件：** 阶段 16 · 04 （原始模型）  
**时间：** ~60 分钟  

## 问题

自一致性（Self-consistency）——对同一个模型采样多次并取多数答案——是你能轻松加上的最便宜的推理改进。它有效，但饱和得很快。你可以翻倍采样，但不会见到有意义的跃升。

辩论打破了饱和状态。不是从同一个模型独立采样 N 次，而是 N 个代理相互阅读对方的推理并修正。采样之间的相关性降低（它们不再是独立同分布的 i.i.d.），而且收敛点通常是正确的，而 i.i.d. 投票却可能自信地错误。

## 概念

### Du 等人 2023 算法

摘自 arXiv:2305.14325（ICML 2024）：

1. N 个代理分别对问题生成初始答案。  
2. 对于第 r 轮（r=2..R）：每个代理展示其他代理第 r-1 轮的答案，并被问到“考虑这些，给出你的更新答案。”  
3. 经过 R 轮后，对最终答案进行多数投票。  

论文测试了 MMLU、GSM8K、人物传记、MATH 和事实性基准。辩论持续击败 CoT 和自我反思（Self-Reflection）。

### 两个独立的调节参数

同一篇论文中的消融实验：

- **仅代理数量**（1 轮，N 个的多数投票）在大多数任务上优于单代理，但达到平台期。  
- **仅轮次数**（1 个代理查看自己的先前推理）几乎无效——反思（Reflection）的已知弱点。  
- **两者结合**带来大幅度提升。多代理之间的多轮交流驱动了收益。  

### 为什么有效

两个机制：

1. **暴露分歧。** 当代理看到另一个代理有不同结论的推理链时，需要要么辩护，要么更新。无论哪种方式，第 r+1 轮的上下文都比第 r 轮更丰富。  
2. **相关错误的减少。** 自一致中，所有样本来自同一个模型，错误是相关的——你平均成一个自信的错误答案。不同模型或不同随机种子会降低相关性。不同的*辩论观点*进一步降低相关性。  

### 异构辩论

A-HMAD 和相关后续工作采用*不同底层模型*为不同代理。Llama + Claude + GPT 共同辩论减少单一模型崩溃问题（第 26 课），因为一个模型家族的相关错误不会被其他模型共享。

缺点：弱模型参与辩论可能会把共识带向其错误答案（详见《Should we be going MAD?》，arXiv:2311.17371）。

### NLSOM——129 代理扩展

Zhuge 等人（《Mindstorms in Natural Language-Based Societies of Mind》，arXiv:2305.17066）将此理念扩展到 129 个成员组成的社会。结果是：随着规模扩大，出现了专业化和自组织，且系统在视觉问答等任务上优于单代理。

### 失败模式

- **谄媚级联。** 所有代理都屈从于说得最自信的代理，辩论崩溃为最吵的声音。引导其中一个代理扮演对立角色（“一代理必须持反对立场”）有助缓解。  
- **主题漂移。** 多轮辩论容易偏离原始问题。缓解方法：每轮重新输入问题。  
- **计算爆炸。** N 代理 × R 轮 = N·R 次 LLM 调用，每次调用的上下文都在增长。5 代理、5 轮辩论等于 25 次调用，且上下文越来越大。每个问题的成本可能超过单次 CoT 调用的 10 倍。  

## 构建它

`code/main.py` 演示了一个 3 代理 × 3 轮的数学问题辩论，每个代理起始答案可能不同（可能错误）。代理是脚本化的——每个代理通过对邻居答案按照脚本的信心水平均值进行“更新”。收敛过程在逐轮日志中清晰可见。

演示呈现两个关键效果：

- 一轮交流后，代理更接近正确答案。  
- 第二轮之后递增效果递减（符合 Du 等人早期的结论）。  

运行：

```text
python3 code/main.py
```

## 使用它

`outputs/skill-debate-configurator.md` 配置适用于新任务的辩论：代理数量、轮数、异质性（同模型或混合模型）、角色分配（对称或一方对立）。还会在运行前估计令牌消耗。

## 发布它

如果要发布辩论功能：

- **最多 3 轮。** Du 等人表明 3 轮几乎捕获全部收益，更多轮数增加成本而非质量。  
- **最多 5 个代理。** 超过 5 个，上下文膨胀和成本成为主导。  
- **默认异构。** 至少保证池中有两个不同底层模型。  
- **对抗角色。** 一个代理总被提示发出异议，破除谄媚现象。  
- **记录每轮。** 藏起中间轮次的辩论系统无法被调试或审计。  

## 练习

1. 运行 `code/main.py`，将轮数设为 5，观察收益递减。在哪一轮以后额外收敛停止？  
2. 增加第四个带有对抗角色的代理：总是不同意当前多数答案。它会破坏还是提升收敛？  
3. 绘制（打印）每轮的协议分（同意多数答案代理的比例）。何时达到 1.0？这是否等同于“正确”？  
4. 阅读 Du 等人第 4 节消融实验。使用这份代码复现“仅代理” vs “仅轮数” vs “两者”结果。  
5. 阅读《Should we be going MAD?》（arXiv:2311.17371），列举两种轮流制以外的辩论变体，如法官引导的、链式辩论、对抗式等。  

## 关键词

| 词条         | 通俗说法           | 实际含义                                                    |
|--------------|--------------------|------------------------------------------------------------|
| Society of Mind | “明斯基的理念”    | 智能是相互协作的专家组成的社会；1986 年框架现通过 LLM 辩论实现。 |
| Multi-agent debate | “代理辩论”       | N 代理提出、批判并修正，经过 R 轮，最终多数投票达成答案。       |
| Consensus    | “他们达成一致”     | 不是认识论上真理，只是多数答案分数。可能自信地错误。              |
| Rounds      | “交换轮次”          | 一轮=每个代理阅读其他人并更新答案一次。                         |
| Heterogeneous debate | “混合模型族”   | 使用不同底层模型来减少错误相关性。                               |
| Sycophancy cascade | “大家都附和最响亮的” | 辩论失败，代理无视正确性，盲从最自信的代理。                   |
