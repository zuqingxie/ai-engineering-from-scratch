# 投票、自洽性与辩论拓扑

> 最廉价的聚合方式：采样N个独立agent，采用多数投票。Wang等人2022年的自洽性（self-consistency）是用同一个模型采样N次实现的。多智能体（multi-agent）则通过**异质性**agent逃离单一文化——不同模型、不同提示词、不同温度、不同上下文。除了多数投票，辩论拓扑结构也很重要：MultiAgentBench（arXiv:2503.01935，ACL 2025）评估了星形／链状／树状／图状协调，发现**图状结构最适合科研任务**，在超过4个agent后有“协调税”（coordination tax）。AgentVerse（ICLR 2024）记录了两种Emergent Patterns——志愿行为和从众行为——从众既是寻找共识的特性，也存在群体思维风险（第24课）。本课将绘制拓扑空间图，构建各变体，测量协调税。

**类型：** 学习+构建  
**语言：** Python（标准库）  
**先修：** 第16阶段·07（心智社会与辩论）、第16阶段·14（共识与拜占庭容错）  
**时长：** 约75分钟

## 问题

辩论能够提升准确率（Du等人，arXiv:2305.14325），但也可能降低准确率。辩论是否有用取决于四个结构性选择：

1. 谁和谁交流（拓扑结构）。  
2. 轮次多少（Du 2023：轮次和agent数量独立影响）。  
3. agent是否异质（不同基础模型打破单一文化）。  
4. 是否存在对抗性声音（强辩与稻草人辩论）。

直接在任务上“运行5个agent再投票”往往会比单个agent表现更差，这种失败模式不是随机的，它们和拓扑结构、异质性相关。本课即为拓扑图谱。

## 概念

### 自洽性，单模型基线

Wang等人2022年（“Self-Consistency Improves Chain of Thought Reasoning”）采样同一个模型N次，温度大于0，对推理路径答案做多数投票。在GSM8K任务中：N=40时，相比单次贪心解码获得显著提升。自洽性是单agent投票的前身。

局限：自洽性基于单个基础模型，错误天然相关。如果模型存在系统偏差，所有N次采样共享该偏差。

### 多智能体投票，异质扩展

将N个采样替换为N个*不同*agent。不同基础模型（Claude、GPT、Llama）、不同提示词、不同工具接入。优势：错误不相关。代价：不同agent成本各异；协调增加开销。

2026年经典术语为**A-HMAD**——对抗性异质多智能体辩论（Adversarial Heterogeneous Multi-Agent Debate）。此名尚未完全普及，但已有论文使用，指“不同模型之间辩论，减少单一文化产生的相关错误”。

### 四种拓扑结构

```text
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           （全连接图）
```

星形（Star）：一个中心节点，其他节点只和中心交流。相当于主管-工人，没有反馈通道。  
链状（Chain）：线性结构，每个agent只看到前一个的输出。类似流水线。  
树形（Tree）：层级结构，用于层次化agent系统（第06课）。  
图形（Graph）：任意双向连接，包括全连接团和任意DAG。

### 协调税（MultiAgentBench）

MultiAgentBench（MARBLE，ACL 2025，arXiv:2503.01935）对星形、链状、树形和图形拓扑，在科研、编程、规划等任务上进行了基准测试。主要结果：

- **图形**拓扑科研任务胜出。信息任意流动，agent可相互批判。  
- **星形**拓扑快答事实任务胜出。中心节点过滤整合信息。  
- **链状**拓扑逐步流水线任务胜出。分阶段优化。  
- **协调税**在图形拓扑中超出约4个agent后显现。时钟和token成本增速快于质量提升。

4-agent天花板是经验值非原则性限制。它反映了2026年LLM上下文容量：当每个agent的上下文都被其他agent的输出填满后，新增第N+1个agent的边际收益下降。

### 多智能体辩论策略（“我们应该采用MAD吗？”）

arXiv:2311.17371为2023年MAD策略综述。关键发现被多个研究复制：结构上类似自洽性（独立采样+聚合）的MAD变体，使用相同预算时常不及自洽性。MAD优势显现于agent真正异质并且辩论含有对抗结构（有agent反对）的情况下。

### AgentVerse中的Emergent Patterns

AgentVerse（ICLR 2024，https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf）记录了无设计介入的两种多智能体辩论自然涌现行为：

- **志愿者行为（Volunteer）**：agent主动提出帮助（“我可以执行下一步”）。有用：将子任务分配给最能干的agent。  
- **从众行为（Conformity）**：agent调整立场以匹配批评者，即使批评者是错的。这是辩论版的谄媚（第14课）。

从众行为导致“直到达成一致”的辩论奖励欺凌者。有边界轮次和独立裁判可缓解。

### 异质性：影响准确率的实际调节器

2024-2026实践文献的模式发现：用不同基础模型替换N个agent中的一个，比单纯增加一个agent的准确率提升更大。直觉是单一文化的问题——每个新独立错误源比新增相关样本更有价值。

极限情况下，异质性优于数量。三个不同模型通常胜过五个相同模型副本，尤其在有明确标准答案的任务中。

### 陪审团方法（Jury methods）

Sibyl框架（Minsky-LLM文献中提及）形式化了“陪审团”——一小组专业agent在每个阶段通过投票细化答案。区别于普通多数投票，陪审团有角色分工：有agent负责交叉质询，负责上下文提供，负责评分合理性。陪审团方法介于普通投票（廉价但易陷入单一文化）和全MAD（昂贵且易从众）之间。

### 何时投票兼辩论胜出

- 问题有明确答案（事实、数学、代码表现），投票收敛有意义。  
- agent能访问不同信息源或工具（存在异质性）。  
- 轮次有限（典型2-3轮），有独立裁判或验证器。  
- 预算支持3-5个agent。超过5-7个时图状拓扑协调税不利。

### 何时投票兼辩论失效

- 问题为观点型。agent趋向于最自信答案，不一定最正确。  
- 全部agent共享同一基础模型。单一文化共识无意义。  
- 无限轮次。从众行为常胜出。  
- 任务简单。单个agent的N=5自洽性成本更低且同样准确。

## 构建

`code/main.py`实现：

- `run_star(agents, hub, question)`——中心poll各worker并汇总。  
- `run_chain(agents, question)`——顺序迭代细化。  
- `run_tree(root, children, question)`——二级层次聚合。  
- `run_graph(agents, question, rounds)`——全连接辩论，有限轮次。  
- 脚本化异质性调节：每个agent有`error_bias`指示其系统性错误倾向。  
- 一个测量框架，N分别取3、5、7，报告（准确率、总token数、模拟墙时）。

运行：

```text
python3 code/main.py
```

预期输出：拓扑×N →（准确率、token数、延迟）表。科研任务中图状拓扑N=3-5胜出；快答事实任务星形胜出；N=7时图状出现协调税（延迟增长快于准确率）。

## 使用

`outputs/skill-topology-picker.md`是一个技能，根据任务描述推荐拓扑（星形/链状/树状/图状）、N（agent数）、异质性配置（使用基础模型组合）、轮次限制。

## 交付

任何集成：

- 从**N=5的单一强模型自洽性**开始，作为廉价基线。  
- 若准确率重要，升级到**N=3的异质投票**。测量差值。  
- 仅当任务有结构性（科研、多步）且轮次有限时，考虑升级至**辩论拓扑**。  
- 始终记录少数派簇。少数派持续正确时是多样性信号。  
- 伴随准确率参考墙时和token消耗，权衡“准确率提升10倍成本是否合理”。

## 练习

1. 运行`code/main.py`。绘制图状拓扑的协调税曲线：准确率随N变化，token数随N变化。曲线在哪个N发生拐点？  
2. 实现A-HMAD：三agent分别带不同偏差。将单一偏差基线与A-HMAD在第14课的单一文化攻击上效果对比。  
3. 给图状拓扑加一个“裁判”角色，不投票，仅评分最终共识。此举是否改变了涌现的从众行为？  
4. 阅读AgentVerse论文（ICLR 2024）。识别你实现中最强的涌现行为。是否通过修改提示词激发相反行为？  
5. 阅读MultiAgentBench（arXiv:2503.01935）第4节（拓扑实验）。用你的框架复现论文中“图状赢科研”结果。

## 关键词

| 术语 | 常说的含义 | 实际意义 |
|------|------------|----------|
| Self-consistency（自洽性） | “采样N次，投票” | Wang 2022。单模型，N次温度>0采样，多数投票推理路径。 |
| Heterogeneity（异质性） | “不同模型” | 不同基础模型或提示家族组成的集成。打破单一文化。 |
| MAD（多智能体辩论） | “多agent辩论” | agent间轮次交换批评的通用术语。见Du 2023。 |
| A-HMAD | “对抗性异质MAD” | 强调不同模型+对抗结构的MAD变种。 |
| Topology（拓扑） | “谁和谁说话” | 星、链、树、图。决定信息流。 |
| Coordination tax（协调税） | “边际递减收益” | 图拓扑4agent以上，成本增速快于质量。 |
| Volunteer behavior（志愿者行为） | “主动帮助” | AgentVerse涌现模式：agent主动承担步骤。 |
| Conformity behavior（从众行为） | “压力下趋同” | AgentVerse涌现模式：agent顺从批评者。 |
| Jury（陪审团） | “小型专业小组” | Sibyl式集成，有分工角色（质询、上下文、评分）。 |
