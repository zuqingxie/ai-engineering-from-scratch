# LLM 的群体优化（PSO, ACO）

> 生物启发的优化方法正在让 LLM 重振旗鼓。**LMPSO**（arXiv:2504.09247）使用粒子群优化（PSO），其中每个粒子的速度是一个提示（prompt），LLM 生成下一个候选输出；对结构化序列输出（数学表达式、程序）效果很好。**Model Swarms**（arXiv:2410.11163）将每个 LLM 专家视作模型权重流形上的 PSO 粒子，在9个数据集上仅用200个实例对12个基线模型实现了**13.3%平均提升**。**SwarmPrompt**（ICAART 2025）将 PSO 和灰狼算法混合应用于 prompt 优化。**AMRO-S**（arXiv:2603.12933）借鉴蚁群算法（ACO），作为多智能体 LLM 路由的费洛蒙专家 —— 实现了**4.7 倍加速**，提供可解释的路由证据，以及基于质量门控的异步更新，解耦推理与学习。本课将实现 PSO 在 prompt 参数空间上的应用，ACO 在智能体路由上的应用，分析这些经典算法为何适合 LLM 时代及其局限。

**类型：** 学习 + 实战  
**语言：** Python （标准库）  
**先修课程：** 阶段16·09（并行群网络）、阶段16·14（共识与拜占庭容错）  
**时长：** 约75分钟

## 问题

你有一个 prompt，在你的任务评估中得分62%。你想提升它。最朴素的方法是无梯度的手动调优，扩展性差；强化学习需要奖励信号和足够的 rollout 来训练。通过 prompt 反向传播实际上不可行 —— prompt 是离散字符串，非可微参数。

经典的生物启发优化——PSO 用于连续搜索空间，ACO 用于路径选择——正是为这种无梯度、基于群体、单次评估成本低的场景设计。将它们与 LLM 结合，用于无梯度搜索步骤，会成为意外实用的优化器。

同样的模式适用于多智能体系统中的智能体*路由*。ACO 风格的费洛蒙路径记录哪个智能体在何种任务类型表现最佳，路由器据此利用路径，费洛蒙还会衰减以便重新发现最佳路径。

## 概念

### PSO 回顾（Kennedy & Eberhart 1995）

粒子群优化（Particle Swarm Optimization）：在连续搜索空间中有一群粒子。每个粒子有位置 `x_i` 和速度 `v_i`。每次迭代：

```text
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

其中 `p_best` 是粒子自身最佳，`g_best` 是群体最佳，`w, c1, c2` 分别是惯性权重、认知权重、社会权重，`r1, r2` 是随机因子。

### PSO 在 LLM 输出上的应用 — LMPSO

arXiv:2504.09247 将 PSO 适配于 LLM 生成的结构化输出（数学表达式、程序）。每个粒子是一个候选输出。速度是一个*prompt*，描述如何将当前输出向个人/全局最优方向调整。LLM 从速度 prompt 生成新的输出。速度的“惯性”表现为像“做小幅递增修改”之类的 prompt。

适用条件：
- 输出是结构化的（可解析、可评估）。
- 适应度函数自动计算（测试运行、算数评估）。
- 群体规模较小（约10-30粒子），确保 LLM 调用总量可控。

不适用于需要人工审核的适应度评估——每次迭代成本过高。

### Model Swarms

arXiv:2410.11163 将 PSO 从输出层移入*模型*层。每个“粒子”是专家 LLM 模型（参数）。群体通过无梯度更新将参数推向集体最优。在9个数据集和12个基线上，迭代仅200次，报告了13.3%的平均提升。

关键洞察是专家模型彼此已经很接近，位于共享参数流形（adapter 权重、LoRA 变化量）里。在这个低维子空间应用 PSO 成本低且高效。

### ACO 回顾（Dorigo 1992）

蚁群优化（Ant Colony Optimization）：蚂蚁在图上行走，每条路径有费洛蒙轨迹。蚂蚁移动概率受费洛蒙强度加权。完成任务的蚂蚁会根据解的质量沉积费洛蒙。费洛蒙会随时间衰减。

### AMRO-S —— 多智能体路由的 ACO

arXiv:2603.12933 利用 ACO 做多智能体路由。每种任务类型是一个“目的地”；每个智能体是可能路径。费洛蒙加强产生高质量输出的路径。主要贡献：

- **可解释的路由证据。** 费洛蒙强度是人类可读信号。
- **质量门控的异步更新。** 费洛蒙更新仅在质量检查通过后执行，解耦推理与学习。
- **多智能体路由基准实现4.7倍加速。**

质量门控很重要：否则快速但错误的智能体会积累费洛蒙，系统锁死在错误路径。

### 何时用 PSO / ACO 优化 LLM

**使用 PSO：**  
- 搜索空间是连续的或映射到连续参数（prompt 嵌入、LoRA 权重、数值生成参数）。  
- 适应度自动且廉价。  
- 群体规模小（10-30）。

**使用 ACO：**  
- 有路由或路径选择问题。  
- 决策会随时间强化（相同任务类型反复出现）。  
- 需要路线选择的可解释证据。

**避免使用：**  
- 适应度需要人工审核（单次成本过高）。  
- 搜索空间过于离散且组合性强，PSO 无法覆盖（建议用遗传算法）。  
- 需要严格的实时决策延迟（PSO/ACO 相较单次启发式收敛较慢）。

### 为什么生物启发方法仍占优势

梯度法依赖可微分信号。LLM 输出和路由决策不是简单可微。伪梯度方法（强化学习路由器、DPO 风格的 prompt 调优）有效但训练成本高。

PSO 和 ACO 只需要一个*评估器*函数。只要能给候选输出或路由决策打分，就能优化该空间，适用门槛更低。

### 实际限制

- **群体预算。** N 粒子 × T 次迭代 × 每次评估成本。LLM 评估约 0.02 美元一次，20 粒子运行50次迭代约20美元，需合理预算。  
- **探索与利用。** 费洛蒙衰减速率和 PSO 的惯性权重权衡；衰减太快 → 忘记好解，太慢 → 陷入早期局部最优。  
- **灾难性漂移。** 当适应度分布变化（新数据分布）时，算法可能收敛后又发散。需监控最优适应度稳定性。

## 实现

`code/main.py` 实现：

- `LMPSO` — 在数值 prompt 参数（温度、top_k 权重）上的 PSO。每个粒子的“LLM 生成”由脚本化适应度函数模拟。运行30次迭代，展示 g_best 收敛。  
- `AMRO_S` — 类 ACO 路由。3 个智能体，4 种任务类型，费洛蒙矩阵，100 个任务路由。打印任务类型→智能体的分布，展示路径形成。  
- 对比：随机路由与 ACO 路由在同一任务流下质量与延迟表现。

运行：

```text
python3 code/main.py
```

预期输出：  
- LMPSO：g_best 适应度从随机逐步提升至接近最优。  
- AMRO-S：费洛蒙表稳定分配正确智能体；ACO路由比随机提升约30%-40%的质量，同时减少延迟（重试次数下降）。

## 使用指南

`outputs/skill-swarm-optimizer.md` 帮助在 PSO、ACO、遗传算法和梯度优化器间选择，适用于 LLM/智能体优化问题。

## 部署建议

- **从小规模开始。** 10-20 粒子，20-50迭代。仅当收敛曲线明显提升再扩展规模。  
- **记录每次迭代的费洛蒙和 g_best。** 无轨迹调试群体优化器极其困难。  
- **质量门控更新。** 尤其是 ACO 路由：防止错误的快速智能体积累费洛蒙。  
- **分布变化时重置衰减。** 评估分布变更时旧费洛蒙过时，临时重置或提升衰减率。  
- **控制每次迭代成本。** 输出迭代成本指标。PSO 花费$500却提升0.5%的策略不可部署。
