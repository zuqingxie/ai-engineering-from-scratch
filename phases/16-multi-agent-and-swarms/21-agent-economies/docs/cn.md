# 代理经济、代币激励、声誉

> 长期自主代理（METR 的1小时至8小时工作曲线）需要经济代理能力。新兴的**五层堆栈**为：**DePIN**（物理计算）→ **身份**（W3C DID 和声誉资本）→ **认知**（RAG + MCP）→ **结算**（账户抽象）→ **治理**（代理型 DAO）。生产中的代理激励网络包括 **Bittensor**（TAO 子网奖励特定任务模型）、**Fetch.ai / ASI 联盟**（ASI-1 Mini LLM + FET 代币）、以及 **Gonka**（基于 Transformer 的 PoW，将计算重新分配到有生产力的 AI 任务）。学术工作：AAMAS 2025 的去中心化 LaMAS 使用**Shapley 值信用分配**公平奖励贡献代理；谷歌研究“针对大型语言模型的机制设计”提出在单调聚合下采用**二价代币拍卖**支付。此次课程构建了一个最简代理市场，应用 Shapley 值信用分配于多代理流水线，并运行二价代币拍卖，使博弈论机制具体落地。

## 问题

当多个代理共同产生价值但需要各自获得奖励时，多代理系统变得复杂。传统机制——平均分配、最后贡献者全得——不公平且易被操纵。基于联盟的 Shapley 值奖励从构造上公平，但计算昂贵。2025-2026 年的文献推动实用近似：Shapley 采样、单调聚合拍卖，以及基于链上确认贡献累积的声誉。

除了信用分配，领域转向真正的经济代理：Bittensor TAO 奖励挖矿计算以微调子网模型，Fetch.ai/ASI 以 FET 代币奖励 ASI-1 Mini LLM 使用，Gonka 将 Transformer 工作量证明（PoW）重新分配给生产性 AI 任务。现今已有自主交易的代理；问题是如何对齐激励。

本课将代理经济视为特定问题族——信用分配、机制设计、声誉——用最简数学构建，使理念深入人心。

## 概念

### 五层代理经济堆栈

1. **DePIN（物理计算）。** 去中心化基础设施，出租 GPU、存储、带宽。Bittensor 子网、Render Network、Akash。非代理专属，代理使用之。
2. **身份。** W3C 去中心化标识符（DID）为每个代理提供平台无关的持久 ID。声誉累积于 DID。代理网络协议（ANP）用 DID 作为发现层。
3. **认知。** 代理的推理循环：LLM + RAG + MCP。即其他阶段构建的内容。
4. **结算。** 账户抽象（ERC-4337）允许代理从自身余额支付 gas，无需持有 ETH。代理可为服务、彼此或计算付费。
5. **治理。** 代理型 DAO：人类和代理共同投票协议变更，投票权与声誉挂钩。

不是每个生产系统都用到所有五层。Bittensor 用了1、2，部分用3、4，不用5。OpenAI 代理只用3。该堆栈是参考地图，不是必需。

### Bittensor、Fetch.ai、Gonka — 运行状况

**Bittensor（TAO）。** 子网是专门任务（语言建模、图像生成、预测）。矿工提交模型输出。验证者排名；基于质押的评分分配 TAO 奖励。每子网有自己评估。经济启示：为任务特定输出质量付费，而非计算量。

**Fetch.ai / ASI 联盟。** ASI-1 Mini LLM 在 Fetch.ai 网络上运行；用户用 FET 代币支付推理费用。代理即对等方的叙述更强：Fetch 上代理可调用另一代理完成任务并用 FET 支付。

**Gonka。** Transformer 工作量证明（PoW）：所谓“工作”是 Transformer 的前向推理。矿工通过运行有已知正确输出（训练数据）的推理任务获利。资源生产型 PoW，非哈希式 PoW。

截至2026年4月，这三者均达生产级。回报分配不同。Bittensor 奖励相对子网验证者的质量；Fetch 奖励有支付的实用性；Gonka 奖励可验证推理工作。

### Shapley 值信用分配

三个代理协作完成任务，产出得分0.8。各自贡献多少？

Shapley 值：满足四条公理（效率、对称、线性、无关）的唯一信用分配。对代理 `i`：

```text
shapley(i) = (1/N!) * sum(对所有排列 O) (v(S_i_O ∪ {i}) - v(S_i_O))
```

其中 `S_i_O` 是排列 O 中 i 之前的代理集合。实际操作：枚举所有排列，记录每个代理在各排列中的边际贡献，取平均。

N=3时有6种排列，N=10时有360万种排列，实际中采用采样代替枚举。

### 聚合的二价拍卖

谷歌研究（“针对大型语言模型的机制设计”）提出用于聚合 LLM 输出的二价代币拍卖。设：N个代理均提出方案，各自对被选方案有私有价值。拍卖者选最高价方案，支付*第二高价*。在单调聚合条件下（价值仅依赖选中方案，不依赖报价数量），此机制保证真实竞价。

对 LLM 系统重要性在于：可将完成任务外包给多个定价不同的代理；拍卖选出最佳，且公平支付，代理无激励报低或报高价。

### 声誉资本

DID 绑定声誉分数由确认贡献累积。简单更新规则：

```text
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

其中衰减因子 `alpha` 靠近1。声誉具备：

- 读取成本低，用于路由决策（“把难任务派给高声誉代理”）。
- 伪造难度大（随时间累积，与 DID 绑定）。
- 可被削减：验证失败的贡献扣减声誉。

### AAMAS 2025 去中心化 LaMAS

LaMAS 提案（AAMAS 2025）结合了：DID 身份、Shapley 值信用分配和简单拍卖机制。核心观点：去中心化信用分配使系统可审计，免受单点操纵。

### 经济机制的脆弱点

- **价格预言机操纵。** 若信用函数可被操控，代理必然作假。每机制需经过对抗测试。
- **Sybil 攻击。** 操作者大量生成虚假代理以提高自己贡献。DID 缓解但不完全阻止，声誉的造假成本是防御措施。
- **验证成本。** 信用分配公平程度取决验证方。若验证便宜（小型 LLM），易被操纵；若验证昂贵（人类评审），则规模受限。
- **监管风险。** 代理经济与金融监管交叉。2026年，Bittensor、Fetch 和 Gonka 在若干司法辖区内处于法律灰色地带。

### 代理经济适用场景

- **开放网络且运营方异构。** 无单一团队控制所有代理。
- **结果可验证。** 无验证的信用分配纯属猜测。
- **长期工作流。** 一次性任务难以获益于声誉积累。
- **代币支付在本地合法有效。**

闭环企业系统中，经济机制往往被简化分配取代（由管理者分派工作，度量内部管理）。经济文献主要适用于开放网络。

## 部署建议

2026年运行代理经济的建议：

- **从声誉开始，不急于代币。** 声誉成本低且本身有价值；代币增加法律与经济复杂度。
- **奖励前先验证。** 未经独立验证不可分配信用。自报质量易产生 Sybil 攻击。
- **采用 Shapley 采样非精确枚举。** 采样100-1000次即可，精确不具备扩展性。
- **限制衰减因子并设声誉下限。** 无上限衰减会抹杀合法贡献者；衰减过慢则奖励过时的高声誉代理。
- **机制需经过对抗性审计。** 网络开放前进行红队测试。每机制存在博弈漏洞，应主动寻找弱点而非攻击者。

## 关键词

| 术语           | 常见表述           | 实际含义                           |
|----------------|--------------------|---------------------------------|
| DePIN          | “去中心化物理基础设施” | 代币激励的计算/存储/带宽。如 Bittensor，Akash，Render。 |
| DID            | “去中心化标识符”       | W3C 标准的可移植 ID。代理声誉绑定于 DID 而非某平台。   |
| ERC-4337       | “账户抽象”           | 可为 gas 代付的合约账户，支持代理支付。                 |
| Shapley value  | “公平信用分配”        | 满足效率、对称、线性、无关公理的唯一分配方案。           |
| Second-price auction | “维克里拍卖”       | 真实竞价机制：中标者支付第二高价。兼容单调聚合。           |
| Reputation capital | “累积质量分”        | 绑定于 DID 的确认贡献得分，随时间衰减。                   |
| Agentic DAO    | “代理与人类共治”      | 代理投票者作为一等公民的 DAO，投票权与声誉关联。          |
| TAO / FET / GPU 代币  | “代币单位”           | Bittensor TAO，Fetch.ai FET，各类 DePIN 代币。              |
