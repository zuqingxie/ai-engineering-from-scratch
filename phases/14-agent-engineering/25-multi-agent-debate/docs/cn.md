# 多智能体辩论与协作

> Du 等人（ICML 2024，“心智社会（Society of Minds）”）运行 N 个模型实例独立提出答案，然后经过 R 轮相互批评以达成共识。提高事实性、规则遵循和推理能力。稀疏拓扑在令牌成本上优于全连接拓扑。

**类型：** 学习 + 实践  
**语言：** Python（标准库）  
**先决条件：** 第14阶段 · 12（工作流模式）、第14阶段 · 05（自我优化 Self-Refine 与 CRITIC）  
**时间：** 约 60 分钟

## 学习目标

- 解释辩论协议：N 个提案者，R 轮，汇聚于共享答案。  
- 描述辩论为何提升事实性、规则遵守和推理能力。  
- 说明稀疏拓扑：并非所有辩手都需要看到所有其他人。  
- 实现标准库脚本化大语言模型（LLM）上的全连接和稀疏变体辩论；测量令牌成本与准确率的关系。

## 问题背景

自我优化（第05课）是一个模型自我批评——存在群体思维风险。CRITIC（第05课）以外部工具为依据进行批评——不总是可用。辩论引入第三种方式：多个实例交叉批评，通过分歧收敛。

## 概念阐述

### 心智社会（Du 等，ICML 2024）

- N 个模型实例独立对同一问题提出答案。  
- 经过 R 轮，各模型阅读其他提案并进行批评。  
- 模型根据批评更新答案。  
- R 轮后，返回汇聚的答案。

原始实验受成本限制，采用 N=3，R=2。难题（MMLU，GSM8K，国际象棋走子有效性，传记生成）上，更多智能体和更多轮数提升准确率。

跨模型组合优于单模型辩论：ChatGPT + Bard 联合 > 任一单独模型。

### 稀疏拓扑

“基于稀疏通信拓扑改进多智能体辩论”（arXiv:2406.11776，2024-2025）指出全连接辩论并非总是最优。稀疏拓扑（星型、环形、枢纽-辐射）能在较低令牌成本下匹配准确率。每个辩手仅看到部分同行。

影响：

- 全连接 N=5，R=3 = 5 × 3 = 15 次提案，每次阅读 4 位同行 = 60 次批评操作。  
- 星型 N=5，R=3（1个枢纽 + 4个辐射）= 15 提案，辐射节点只读枢纽 = 12 次批评操作。

### 何时辩论有效

- **事实性。** N 个独立提案，交叉验证减少虚构（hallucination）。  
- **规则遵守。** 棋步有效性——一个模型漏判规则，其他模型纠正。  
- **开放式推理。** 多重框架聚焦正确答案。

### 何时辩论弊端

- **延迟敏感的用户体验。** N × R 串行轮数造成的延迟可能无可容忍。  
- **成本敏感的规模。** 每题消耗 N × R 令牌。  
- **简单事实查询。** 一次查询比多次辩论成本低。

### 2026 年实际应用

- **Anthropic 编排者-工人**（第12课）——带有合成步骤的辩论变体。  
- **LangGraph 监督者**（第13课）——中央路由 + 专家智能体实现作为节点的辩论。  
- **OpenAI Agents SDK**（第16课）——智能体反复交接进行迭代批评。  
- **多智能体评估**——配对辩论 + 评估-优化器获得评估信号。

### 该模式风险点

- **收敛塌陷。** 所有智能体收敛到第一个错误答案。通过强制异议轮数缓解。  
- **枢纽失效。** 星型拓扑中，枢纽异常影响所有人。采用轮换或多个枢纽。  
- **提示同质化。** 全部智能体用同一提示，答案趋同。使用多样化提示或不同模型。

## 实践构建

`code/main.py` 实现标准库辩论：

- `Debater` 类（脚本化 LLM，带个体意见漂移）。  
- `FullMeshDebate` 和 `SparseDebate` 运行器。  
- 三个问题：一个事实验证，一个基于规则，一个推理题。  
- 指标：汇聚答案、收敛轮数、批评操作总数。

运行：

```bash
python3 code/main.py
```

输出：各协议准确率与成本；稀疏方法在三题中两题低成本匹配全连接准确率。

- **LangGraph** 用于带检查点的多轮状态辩论。

## 练习

1. 实现“强制异议”规则：第 1 轮每位辩手必须给出不同提案。衡量对收敛速度的影响。  
2. 添加置信度加权聚合：辩手返回（答案，置信度），聚合器按置信度加权。效果如何？  
3. 替换一个“智能体”为拥有不同观点的脚本化 LLM。异质性是否提升准确率？  
4. 测量三题的全连接与稀疏令牌成本。绘制成本-准确率图。  
5. 阅读《心智社会》论文。将小项目扩展到 N=5，R=3。问题与收获何在？

## 关键词

| 术语             | 常见说法            | 实际含义                      |
|------------------|---------------------|------------------------------|
| Debate（辩论）   | “多智能体批评”        | N 个提案者，R 轮交叉批评，收敛   |
| Full mesh（全连接） | “人人阅读人人”        | 每位辩手每轮阅读所有同行            |
| Sparse topology（稀疏拓扑） | “有限同行视野”      | 辩手只阅读部分同行              |
| Hub-and-spoke（枢纽辐射） | “星型拓扑”           | 一个中央辩手，N-1 辐射只读枢纽      |
| Convergence（收敛） | “达成共识”            | 辩手达成共享答案               |
| Society of Minds（心智社会） | “Du 等辩论论文”        | ICML 2024 多智能体辩论方法         |
