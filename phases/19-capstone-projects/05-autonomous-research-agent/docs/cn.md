# 毕业设计 05 — 自动化研究代理（AI-Scientist 类）

> Sakana 的 AI-Scientist-v2 发表了完整论文。Agent Laboratory 运行了实验。Allen AI 分享了轨迹。2026 形态是基于实验的计划-执行-验证树搜索，预算成本控制，沙箱代码执行，视觉反馈的 LaTeX 撰写器，以及自动化的 NeurIPS 风格评审组装。毕业设计是构建一个完整系统，在每篇论文不超过 30 美元的情况下端到端运行，并且通过 Sakana 文档记录的沙箱逃逸红队测试。

**类型：** 毕业设计  
**语言：** Python（代理 + 沙箱）、LaTeX（输出）  
**先修课程：** 阶段 2（机器学习 ML）、阶段 3（深度学习 deep learning）、阶段 7（Transformer（Transformer 架构））、阶段 10（从零构建大型语言模型 LLMs）、阶段 14（智能代理 agents）、阶段 15（自主 autonomous）、阶段 16（多代理 multi-agent）、阶段 18（安全 safety）  
**涉及阶段：** P0 · P2 · P3 · P7 · P10 · P14 · P15 · P16 · P18  
**时长：** 40 小时  

## 问题

自主研究代理在 2026 年达到了一个临界点。Sakana AI 的 AI-Scientist-v2 发表在 Nature，生成的论文通过了研讨会同行评审。ShinkaEvolve（ICLR 2026）将方向扩展到进化假设。AMD 的 Agent Laboratory 发布了可复现的轨迹。代理并非魔法——它们是在候选实验树上运行的计划-执行-验证循环，具有成本上限、种子绑定的沙箱和自动化评审。核心在于循环本身、预算控制和安全故事。

你将通过在一个狭窄领域内实现一套基于种子想法的循环来学习（例如，基于 1 亿参数 Transformer 架构的注意力稀疏度消融实验）。价值不在于首次运行发现惊喜，而在于构建基础设施：树搜索、实验沙箱、撰稿-评审循环、红队报告。Sakana 团队记录了沙箱逃逸的失败案例；你的代理必须通过同样的红队测试。

## 概念

代理是一个最佳优先树搜索。节点是实验规格：（假设、配置、代码、预期结果）。扩展步骤提出修改细节的小规模子节点（更换优化器、调整批量大小、消融组件）。每个子节点在一个有严格资源限制的全新沙箱中运行。结果反馈给评分函数，用（新颖性 × 质量 × 剩余预算）对节点排序。树不断生长直到预算耗尽，选出最佳分支生成论文。

撰稿器是多模态的。它生成 LaTeX 草稿，编译，绘图，并将渲染的 PDF 反馈给 Claude Opus 4.7 的视觉模式，获取关于版式、图形清晰度和论据证据对齐的批评。评审组装由五个 LLM 评审组成，输出 NeurIPS 风格的评分（新颖性、严谨性、清晰性、可复现性、影响力）；若平均分低于门槛，论文返回撰稿器修改。

安全是基础。每个实验都在 E2B 或 Daytona 沙箱中运行，无网络出口，限制实际运行时间和资源。代理的代码生成经过策略层过滤，阻断逃逸沙箱的系统调用。红队报告重现 Sakana 文档中攻击面（fork炸弹、文件系统逃逸、LLM 编写的网络调用）。

```text

      |

  |                 |      (E2B / Daytona)
```

## 技术栈

- 编排：LangGraph，支持检查点和人工审批闸门  
- 树搜索：针对实验节点的定制最佳优先搜索（基于 Sakana v2 的 AB-MCTS 风格）  
- 沙箱：每个实验运行 E2B；Docker-in-Docker 备用方案；通过 cgroups 实现资源控制  
- 文献：Semantic Scholar Graph API + OpenAlex + 本地 FAISS 摘要缓存  
- 撰稿器：LaTeX 模板 + Claude Opus 4.7（视觉模式）用于图形批评与排版  
- 评审器：5 名评审组成的集成（Opus 4.7, GPT-5.4, Gemini 3 Pro, DeepSeek R1, Qwen3-Max），加权汇总  
- 实验框架：PyTorch 2.5 执行物理实验，W&B 记录日志  
- 可观察性：Langfuse 监控代理轨迹，单篇论文最高 30 美元硬预算  

## 构建步骤

1. **种子与领域范围定义。** 挑选一个种子想法（如“研究亚 10 亿参数 Transformer 注意力图的稀疏模式”）。定义搜索空间：模型、数据集、计算预算。  

2. **文献检索。** 查询 Semantic Scholar + OpenAlex，获取 50 篇相关高引用论文；本地缓存摘要；生成 1 页领域综述。  

3. **树形结构搭建。** 以种子假设初始化根节点。实现 `expand(node) -> children` ，提供小幅配置修改的子节点（每子节点一个配置更改）。实现 `score(node)` 为加权的新颖性 × 质量 × 预算函数。  

4. **沙箱封装。** 每个实验执行时都跑 `docker run --network=none --memory=8g --cpus=2 --pids-limit=256 --read-only` （或等效的 E2B 策略）。将种子写入沙箱；输出以只读方式映射回外部。  

5. **计划-执行-验证循环。** `plan` 提出子节点。`execute` 运行沙箱，捕获日志和指标。`verify` 对指标运行单元检测（损失是否下降？消融是否隔离了影响？）。失败节点在树上记录失败原因。  

6. **撰稿。** 预算用尽后，选出最佳分支。用 matplotlib 生成图形。通过 Claude Opus 4.7 根据分支轨迹生成 LaTeX 草稿。编译。将编译生成的 PDF 反馈给 Opus 4.7 视觉模式批评。循环迭代。  

7. **评审组装。** 五个评审员用 NeurIPS 评分尺度评估草稿（新颖性、严谨性、清晰性、可复现性、影响力）。若平均得分 < 4.0 / 5，则将论文退回修改，最多可重写 3 次。  

8. **红队检测。** 构建或集成针对沙箱的对抗性任务：fork 炸弹，网络外泄企图，文件系统逃逸，LLM 编写的 shell 元字符。确认所有均被阻断。撰写测试报告。  

9. **可复现性。** 每篇论文附带树搜索轨迹 JSON、种子、W&B 运行链接、沙箱配置和复现说明文档，支持端到端复现。

## 交付物

`outputs/skill-ai-scientist.md` 是最终产物。给定种子想法 + 领域 + 30 美元预算，它运行完整流水线，输出可评审的论文及可复现包。

| 权重 | 标准 | 评估方式 |
|:-:|---|---|
| 25 | 论文质量 | 盲评对比已发布研讨会论文 |
| 20 | 实验严谨性 | 基线、种子、消融；每条结论都有结果表单元支持 |
| 20 | 成本与计算纪律 | 每篇论文最高 30 美元限制，Langfuse 监控 |
| 20 | 安全性 | 沙箱红队测试通过；网络策略和紧急终止开关验证 |
| 15 | 可复现性 | 一条命令重现，种子相同，论文一致 |
| **100** | | |

## 练习

1. 对同一领域的三个不同种子想法运行流水线。比较树搜索重叠部分，识别重复浪费计算的区域。

2. 在估计成本超过 5 美元的节点执行前增加人工审批闸门。测量成本下降幅度。

3. 替换评审组为单个评审员。测定对已知劣质论文持假通过率。

4. 引入网络外泄红队测试：让代理写代码尝试 `curl` 外部地址。确认 `--network=none` 策略阻断。记录日志。

5. 将你的树搜索与同预算下的平面随机基线对比。报告新颖度 × 质量提升。

## 关键词

| 术语 | 通常说法 | 实际含义 |
|------|----------|----------|
| 树搜索 | “AB-MCTS 风格扩展” | 基于实验节点的最佳优先探索，评分基于新颖性×质量×预算 |
| 沙箱 | “实验隔离” | 无网络、限制 CPU/内存、固定种子、只读输入的容器环境 |
| 视觉批评 | “编译-再读” | 将论文编译成 PDF，反馈给视觉大模型执行版式和论据验真批评 |
| 评审组装 | “自动同行评审” | 多个 LLM 评审者基于 NeurIPS 评分标准打分；加权汇总控制流水线 |
| 新颖度评分 | “这新么？” | 对照 50 篇论文文献缓存，距离越近惩罚越大 |
| 成本上限 | “美元预算” | 每篇论文硬性花费上限；配合 Langfuse 计数和预跑估计|
| 红队 | “沙箱逃逸审计” | 模拟可能的攻击行为，验证策略能否阻断沙箱逃逸 |
