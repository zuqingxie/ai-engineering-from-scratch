# 多模态评估

> 训练是循环的一半。另一半是测量。本课从基本元素构建三个评估面：图像-文本检索以 R@1、R@5、R@10 报告；视觉问答（VQA）以完全匹配准确率报告；图像描述以 BLEU-4 报告。每个指标都是模型输出与合成评估套件的函数，运行时间为几秒。

**类型：** 构建  
**语言：** Python  
**前置知识：** 第 19 阶段第 58-62 课（E 轨道基础：编码器、Transformer（Transformer 架构）、投影、交叉注意力融合、预训练）  
**时长：** ~90 分钟

## 学习目标

- 从图像和文本嵌入之间的相似度矩阵计算 Recall@K（召回率@K）。
- 从映射（图像，问题）对到固定答案词汇表的模型中计算视觉问答的完全匹配准确率。
- 从生成和参考的标记序列计算 BLEU-4，无需任何外部库。
- 针对基于第 62 课训练模型构建的合成评估套件运行所有三个评估。

## 问题描述

当训练损失趋于稳定时，很容易认为多模态模型训练完成。训练损失度量的是模型对训练分布的拟合度；它不衡量模型是否能在保留的批次中对成对样本排序、回答问题或生成让人类接受的描述文本。常见的三个评估面是：

- **检索（R@1，R@5，R@10）。** 构建查询文本的联合嵌入；按余弦相似度对评估池中的所有图像进行排序；报告匹配的图像是否位于前 1、前 5、前 10。对称的（图像到文本）形式相同。
- **视觉问答（完全匹配准确率）。** 给定（图像，问题）对，模型输出一个答案标记。完全匹配是二分类：预测答案是否等于参考答案？在评估集上平均。
- **图像描述（BLEU-4）。** 生成一句描述。计算 1-gram 到 4-gram 的精确度几何平均值，并带有简洁度惩罚。多参考是标准做法（一图对应多参考描述）。

每个指标都是简单的函数。课程用代码实现它们以具体化数学，且评估面保持在你的掌控范围。真实基准套件（MS-COCO，VQA v2，GQA，OK-VQA）适用于相同函数签名。

## 概念

```mermaid
flowchart TB
  Model[训练好的多模态模型] --> Embed[评估集上的联合嵌入]
  Embed --> Sim[相似度矩阵]
  Sim --> R1[R@1]
  Sim --> R5[R@5]
  Sim --> R10[R@10]
  Model --> VQA[预测每个问题的答案标记]
  VQA --> EM[完全匹配准确率]
  Model --> Caps[生成的描述]
  Caps --> BLEU[相对于参考的 BLEU-4]
```

### 从相似度矩阵计算 Recall@K

构建图像和文本嵌入之间大小为 `(N, N)` 的余弦相似度矩阵。对每一行，将列按降序排序。Recall@K 是对角线列索引在前 K 位的行的比例。对称的 Recall@K（文本到图像）在转置矩阵上计算。两种结果都报告。对于 N=100 的评估，R@1=0.6 表示 100 个文本中有 60 个检索到正确图像作为第一匹配。

### VQA 完全匹配

对于每个（图像，问题，答案），编码图像，嵌入问题，通过解码器融合，输出下一个标记。预测的标记 id 与参考 id 比较，匹配则正确。对评估集取平均。真实 VQA 数据集附带多个人工标注答案，使用软准确率公式（如果至少 3 个标注者中有 1 个同意则为 1.0，较少时按比例缩放）；本课采用单一答案的完全匹配方便理解。

### BLEU-4

```text
BLEU-4 = BP * exp(mean(log p1, log p2, log p3, log p4))
```

其中 `p_n` 是修改后的 n-gram 精确度（生成 n-gram 中在任一参考中出现的被剪裁计数除以总生成 n-gram 数），`BP` 是简洁度惩罚：

```text
BP = 1                如果生成长度 > 参考长度
   = exp(1 - r/g)     否则，其中 r 是参考长度，g 是生成长度
```

对某些 `p_n` 为零的小样本需要平滑。实现用 Chen 和 Cherry 的“方法 1”（任何零计数时分子分母都加 1），这是低计数情况下最安全的默认做法。

### 合成评估套件

一个包含 50 个样本的评估套件在内存中构建，基于第 62 课中相同的模拟语料模式，用保留种子。套件由三份列表组成：

- `pairs`：50 个（图像，caption_ids）对用于检索。
- `vqa`：50 个（图像，question_ids，answer_id）三元组。
- `caps`：50 个（图像，[参考描述标记列表，…]），每个图像最多 3 个参考。

套件由种子确定，且不在训练语料中，确保指标计算在模型未见过的数据上。将套件持久化为 JSON 留作练习（见下）。

| 指标    | 范围  | 随机基线（N=50）        |
|---------|-------|-------------------------|
| R@1     | 0 到 1| 0.02 （1 / N）          |
| R@5     | 0 到 1| 0.10                    |
| R@10    | 0 到 1| 0.20                    |
| VQA EM  | 0 到 1| 1 / 词汇量               |
| BLEU-4  | 0 到 1| 小于但非零               |

合成数据上训练 50 步后，指标不会很高，但应高于随机基线，这就是演示所检验的。

## 实现

`code/main.py` 实现：

- `recall_at_k(sim_matrix, k)`，返回 `[0, 1]` 区间浮点数，双向计算。
- `vqa_exact_match(predictions, references)`，返回整数相等的平均值。
- `bleu4(generated, references, smoothing=True)`，支持多参考。
- `build_eval_suite(seed, n_samples, vocab_size, max_len)`，返回三个确定性评估列表。
- `evaluate(model, suite)`，运行所有三个指标，返回数字型 `dict`。
- 演示代码：加载第 62 课初始化的多模态模型，评估，训练 50 步，再评估并打印前后指标。

运行：

```bash
python3 code/main.py
```

输出：前后指标表显示检索指标从接近随机提升至模型学习信号，VQA 超越随机，BLEU-4 也有所提升（模拟结构足以提升到 4-gram 精确度）。

## 使用

每个指标直接映射到生产基准：

- **检索。** MS-COCO 5K 验证集、Flickr30K、ImageNet 零样本均是基于相同相似度矩阵的 R@K 问题。用真实数据替换模拟评估，函数签名保持不变。
- **VQA。** VQA v2、GQA、OK-VQA 使用相同的完全匹配形式（VQA v2 用软准确率代替单答案）。
- **BLEU-4。** MS-COCO 描述、NoCaps、Flickr30K 描述都使用 BLEU-4 加 CIDEr 和 METEOR。添加 CIDEr 是另一函数。

实际基准中，用真实加载器替换 `build_eval_suite`，保留函数体。数学部分与基准无关。

## 测试

`code/test_main.py` 测试：

- perfect identity 相似度矩阵时 recall@k 返回 1.0，完全翻转矩阵时 k < N 返回 0.0
- recall@k 依赖于 `k <= N` 上限
- 生成序列与任一参考完全相同返回 bleu4 为 1.0
- 不相交词汇返回 0.0
- vqa 完全匹配等于相等对的比例
- build_eval_suite 生成预期数量的 pairs、vqa 条目和描述

## 练习

1. 为描述指标添加 CIDEr。CIDEr 使用 n-gram 的 TF-IDF 权重，奖励信息量较高的标记。

2. 实现软准确率 VQA：每个问题有多个人工答案，准确率为 `min(human_count / 3, 1)`（任何匹配计数），复现 VQA v2。

3. 添加 NaN 安全的 `bleu4` 变体，处理空生成序列不崩溃。

4. 计算平均倒数排名（MRR）并与 R@K 一起报告。MRR 对正确答案在前 K 之后的位置敏感，R@K 关注是否在前 K。

5. 在训练的五个检查点（步数 0、10、20、30、40、50）运行评估，并绘制学习曲线。确认指标轨迹随损失轨迹变化。

## 关键词

| 术语        | 含义                                                     |
|-------------|----------------------------------------------------------|
| R@K         | 正确匹配是否出现在查询结果前 K 的比例                     |
| 完全匹配    | 最简单的 VQA 评分：预测答案是否等于参考答案               |
| BLEU-4      | 1-gram 到 4-gram 精确度的几何平均，带简洁度惩罚           |
| 多参考      | 一个描述指标支持每个图像多个参考描述                       |
| 保留样本    | 评估集从与训练语料不相交的种子中采样                     |
