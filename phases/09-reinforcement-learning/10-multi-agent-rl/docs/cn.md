# 多智能体强化学习（Multi-Agent RL）

> 单智能体强化学习假设环境是平稳的。当两个学习智能体处于同一个世界时，这个假设就不成立：每个智能体都是另一个智能体环境的一部分，且双方都在不断变化。多智能体强化学习是一系列在马尔可夫假设不再成立时使学习收敛的技巧集合。

**类型：** 实践  
**语言：** Python  
**先决条件：** 第9阶段 · 04（Q-learning），第9阶段 · 06（REINFORCE），第9阶段 · 07（Actor-Critic）  
**时间：** ~45分钟

## 问题描述

机器人学习在房间内导航是单智能体强化学习问题。足球队不是。AlphaStar对战星际争霸对手不是。竞标代理市场也不是。两辆车在四路停止标志处协商也不是。多数对多的现实问题也不是。

在每个多智能体场景中，从任一智能体视角看，其他智能体是环境的一部分。随着它们学习并改变行为，环境变得非平稳。马尔可夫性质——“下一状态只依赖当前状态和我的动作”——被打破，因为下一状态还依赖于*其他*智能体的选择，而它们的策略是不断变化的目标。

这破坏了表格法（tabular）收敛证明（Q-learning 的保证依赖于环境平稳）。也破坏了简单的深度强化学习：智能体相互追逐，形成循环，从不收敛到稳定策略。你需要多智能体专用技巧：集中训练/分散执行（centralized training / decentralized execution，CTDE），反事实基线（counterfactual baselines），联赛玩法（league play），自我对弈（self-play）。

2026年应用：机器人群体、交通路由、自动驾驶车队、市场模拟器、多智能体大型语言模型系统（第16阶段），以及任何有多个智能玩家的游戏。

## 概念

![四种多智能体强化学习范式：独立式，集中式评论家，自我对弈，联赛玩法](../assets/marl.svg)

**形式化：马尔可夫博弈（Markov Game）。** MDP 的推广：状态集 `S`，联合动作 `a = (a_1, …, a_n)`，转移概率 `P(s' | s, a)`，每个智能体的奖励 `R_i(s, a, s')`。每个智能体 `i` 在其策略 `π_i` 下最大化自身回报。若奖励相同，则为**完全合作（fully cooperative）**。若零和，则为**对抗（adversarial）**。若混合，则为**一般和（general-sum）**。

**核心挑战：**

- **非平稳性（Non-stationarity）。** 从智能体 `i` 视角看，`P(s' | s, a_i)` 依赖于其他智能体策略 `π_{-i}`，而它是不断变化的。
- **信用分配（Credit assignment）。** 共享奖励时，哪个智能体造成的？
- **探索协调（Exploration coordination）。** 智能体必须探索互补策略，避免重复探索相同状态。
- **可扩展性（Scalability）。** 联合动作空间随智能体数 `n` 指数增长。
- **部分可观测（Partial observability）。** 每个智能体只观察自身的观察值，全球状态隐藏。

**四大主流范式：**

**1. 独立Q学习 / 独立PPO（IQL, IPPO）。** 每个智能体学习自己的Q值或策略，将其他智能体视为环境一部分。简单，有时有效（尤其是经验重放充当平滑代理建模技巧时）。理论收敛：无。实际中适用于松耦合任务，紧耦合任务表现差。

**2. 集中训练，分散执行（CTDE）。** 最常见现代范式。每个智能体有自己基于局部观测 `o_i` 的*策略* `π_i` —— 部署时标准分散执行。训练时，有集中式评论家 `Q(s, a_1, …, a_n)` 基于完全全局状态和联合动作。示例：
- **MADDPG**（Lowe 等，2017）：每智能体一个集中评论家的 DDPG。
- **COMA**（Foerster 等，2017）：反事实基线——问“如果我选择动作 `a'`，奖励会是多少？”——隔离我的贡献。
- **MAPPO** / **IPPO**（Yu 等，2022）：带集中值函数的 PPO。2026年合作MARL主流。
- **QMIX**（Rashid 等，2018）：值分解——`Q_tot(s, a) = f(Q_1(s, a_1), …, Q_n(s, a_n))` 且满足单调混合。

**3. 自我对弈（Self-play）。** 两个相同智能体互相竞技。对手策略是我过去的快照。AlphaGo / AlphaZero / MuZero。OpenAI Five。适合零和游戏，训练信号对称。

**4. 联赛玩法（League play）。** 自我对弈的扩展，适用于一般和和对抗环境：维护过去和当前策略的人口库，从联赛中采样对手，针对其训练。加入剥削者（专门打败当前最优）和主剥削者（打败剥削者）。AlphaStar（星际争霸 II）。在策略循环（石头剪刀布）游戏中必需。

**通信。** 允许智能体间发送学习消息 `m_i`。适用于合作环境。Foerster 等（2016）证明了可微分的智能体间通信可端到端训练。今日基于大型语言模型的多智能体系统（第16阶段）基本用自然语言通信。

## 构建示例

本课例用一个6×6网格世界（GridWorld）和两个合作智能体。它们从相对角落出发，必须到达共享目标。共享奖励：任一智能体还未到达，每步 `-1`，两者均到达时 `+10`。见 `code/main.py`。

### 步骤1：多智能体环境

```python
class CoopGridWorld:
    def __init__(self):
        self.size = 6
        self.goal = (5, 5)

    def reset(self):
        return ((0, 0), (5, 0))  # 两个智能体初始位置

    def step(self, state, actions):
        a1, a2 = state
        new1 = move(a1, actions[0])
        new2 = move(a2, actions[1])
        done = (new1 == self.goal) and (new2 == self.goal)
        reward = 10.0 if done else -1.0
        return (new1, new2), reward, done
```

*联合*动作空间是 `|A|² = 16`。全局状态是两个位置。

### 步骤2：独立Q学习

每个智能体运行自己的以联合状态为键的Q表。每步：双方选取ε-贪婪动作，收集联合转移，用共享奖励分别更新自己的Q。

```python
def independent_q(env, episodes, alpha, gamma, epsilon):
    Q1, Q2 = defaultdict(default_q), defaultdict(default_q)
    for _ in range(episodes):
        s = env.reset()
        while not done:
            a1 = epsilon_greedy(Q1, s, epsilon)
            a2 = epsilon_greedy(Q2, s, epsilon)
            s_next, r, done = env.step(s, (a1, a2))
            target1 = r + gamma * max(Q1[s_next].values())
            target2 = r + gamma * max(Q2[s_next].values())
            Q1[s][a1] += alpha * (target1 - Q1[s][a1])
            Q2[s][a2] += alpha * (target2 - Q2[s][a2])
            s = s_next
```

该任务上有效因为奖励稠密且目标一致。对紧耦合任务失败（例如一个智能体必须*等待*另一个智能体时）。

### 步骤3：集中式Q与价值分解更新

使用一个针对联合动作的Q值 `Q(s, a_1, a_2)`，基于共享奖励更新。执行时去边缘化实现分散决策：`π_i(s) = argmax_{a_i} max_{a_{-i}} Q(s, a_1, a_2)`。用正确的全局视角换取了指数级动作空间。

### 步骤4：简单自我对弈（对抗两智能体）

同一智能体，两个角色。让智能体A对阵B；每隔 `K` 回合，将A权重复制给B。训练对称，进展稳定。AlphaZero微型配方。

## 陷阱

- **非平稳经验重放。** 独立智能体的经验重放比单智能体更糟，因为旧转移由过时对手生成。修复：重标记或按新旧进行加权。
- **信用分配模糊。** 长回合后共享奖励，不清楚哪个智能体贡献。修复：反事实基线（COMA）、或者每智能体的奖励塑形。
- **策略漂移/追逐。** 每个智能体的最优响应随着对方更新而变化。修复：集中评论家，较小学习率，或逐个冻结更新。
- **通过协调作弊。** 智能体找到设计者未预料的协调利用方法。拍卖智能体竞标趋近零。修复：精心设计奖励，行为约束。
- **探索冗余。** 智能体重复探索相同状态动作。修复：每智能体熵奖励，或角色条件。
- **联赛循环。** 纯自我对弈可能陷入优势循环。修复：加入多样对手的联赛玩法。
- **样本爆炸。** `n`智能体 × 状态空间 × 联合动作。用函数逼近；分解动作空间（每智能体一个策略输出头）。

## 应用图谱

| 领域 | 方法 | 说明 |
|--------|--------|-------|
| 合作导航/操作 | MAPPO / QMIX | CTDE；共享评论家 + 分散执行。 |
| 双人游戏（国际象棋、围棋、扑克） | 带蒙特卡洛树搜索的自我对弈（AlphaZero） | 零和；训练对称。 |
| 复杂多人游戏（Dota，星际争霸） | 联赛玩法 + 模仿预训练 | OpenAI Five，AlphaStar。 |
| 自动驾驶车队 | 带注意力机制的CTDE MAPPO / PPO | 部分观测；团队规模可变。 |
| 拍卖市场 | 博弈论均衡 + 强化学习 | `n`→∞ 时以均场强化学习实现。 |
| 大型语言模型多智能体系统（第16阶段） | 自然语言通信 + 角色条件 | 智能体-规划层的强化学习循环。 |

2026年，MARL最大增长领域是基于大型语言模型：语言模型智能体群共同谈判、辩论、构建软件。强化学习体现在*轨迹级别*输出的偏好优化，而非逐token（第16阶段 · 03）。

## 练习

1. **简单。** 在2智能体合作GridWorld上训练独立Q学习。多少回合后平均回报超过0？绘制联合学习曲线。
2. **中等。** 加入“协调”任务：仅当两智能体同回合同时踏上目标才算达成。独立Q还能收敛吗？哪里出问题了？
3. **困难。** 实现一个集中评论家用于MAPPO风格训练，并与独立PPO在协调任务上比较收敛速度。

## 关键词

| 术语 | 大众说法 | 实际含义 |
|------|-----------------|-----------------------|
| 马尔可夫博弈（Markov game） | “多智能体MDP” | `(S, A_1, …, A_n, P, R_1, …, R_n)`；每个智能体有自己奖励。 |
| CTDE | “集中训练，分散执行” | 训练时用联合评论家；每智能体策略只用局部观测。 |
| IPPO | “独立PPO” | 每个智能体独立运行PPO。简单基线；经常被低估。 |
| MAPPO | “多智能体PPO” | 使用集中值函数基于全局状态的PPO。 |
| QMIX | “单调值分解” | `Q_tot = f_monotone(Q_1, …, Q_n)` 允许分散式argmax。 |
| COMA | “反事实多智能体” | 优势 = 我的Q值减去对我动作边缘化的期望Q值。 |
| 自我对弈（Self-play） | “智能体对过去自我” | 单个智能体两角色；零和游戏标准做法。 |
| 联赛玩法（League play） | “种群训练” | 缓存过去策略，从池中采样对手；处理策略循环。 |

## 深入阅读

- [Lowe 等人 (2017)。混合合作-竞争环境中的多智能体演员-评论家（MADDPG）](https://arxiv.org/abs/1706.02275) — 使用集中式评论家的 CTDE（集中训练分散执行）。
- [Foerster 等人 (2017)。反事实多智能体策略梯度（COMA）](https://arxiv.org/abs/1705.08926) — 用于归因的反事实基线。
- [Rashid 等人 (2018)。QMIX：单调值函数分解](https://arxiv.org/abs/1803.11485) — 带有单调性的值分解。
- [Yu 等人 (2022)。PPO 在合作多智能体游戏中的惊人有效性（MAPPO）](https://arxiv.org/abs/2103.01955) — PPO 在多智能体强化学习中的意外强大。
- [Vinyals 等人 (2019)。使用多智能体强化学习达成《星际争霸 II》大师级水平（AlphaStar）](https://www.nature.com/articles/s41586-019-1724-z) — 大规模的联赛玩法。
- [Silver 等人 (2017)。无人工知识掌握围棋（AlphaGo Zero）](https://www.nature.com/articles/nature24270) — 零和游戏中的纯自我对弈。
- [Sutton & Barto (2018)。第 15 章 — 神经科学 & 第 17 章 — 前沿](http://incompleteideas.net/book/RLbook2020.pdf) — 包含教科书中对多智能体设置及 CTDE 设计解决的非平稳性问题的简短讨论。
- [Zhang, Yang & Başar (2021)。多智能体强化学习：精选综述](https://arxiv.org/abs/1911.10635) — 涵盖合作、竞争和混合多智能体强化学习的综述及收敛性结果。
