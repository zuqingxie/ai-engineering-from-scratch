# Scaling Laws（规模定律）

> 2020 年 Kaplan 论文说：模型越大，损失越低。2022 年 Hoffmann 论文说：你训练不足。计算量分为两部分——参数（parameters）和令牌（tokens）——且二者的分配并不明显。

**类型：** 学习  
**语言：** Python  
**前置知识：** 第7阶段 · 05（完整 Transformer（Transformer 架构）），第7阶段 · 07（GPT）  
**时间：** 约 45 分钟

## 问题

当你有 C FLOPs 的训练计算资源并想获得最佳模型时，你面临两个调节项：

1. **参数数量（N）多少？** 模型越大，容量越高。  
2. **训练令牌数量（D）多少？** 数据越多，容量利用得越好。

FLOPs 大致按 `6 × N × D` 计算。你可以把 N 提高，把 D 降低，或者把 D 提高，把 N 降低。哪个更好？

2022 年之前的答案是“尽力推高 N”。GPT-3（2020）有 1750 亿参数，训练了约 3000 亿令牌。参数和令牌的比例约为 1.7 令牌/参数。Kaplan 的规模定律支持这个观点。

Hoffmann 等人（2022）训练了一个名为 Chinchilla 的小型模型系列，发现了不同的结果：最优比例接近 **20 令牌/参数**。GPT-3 的训练量不足了 10 倍。Chinchilla（700 亿参数，1.4 万亿令牌）在所有基准测试上都超过 GPT-3（1750 亿参数，3000 亿令牌），且推理成本降低了 2.5 倍。

2026 年是 Chinchilla 的时代——但带有一个重要转折。Llama 3 8B 训练了 15 万亿令牌，比例为每参数 1875 个令牌。是 Chinchilla 最优比例的 94 倍。对于大规模使用的模型，推理成本比训练成本更重要，因此“过度训练”（超过 Chinchilla）以换取更小的部署占用已成 2026 年的默认策略。

## 概念

![Chinchilla 曲线：不同 N/D 比例下的损失与计算量关系](../assets/scaling-laws.svg)

### Hoffmann 定律

来自 Chinchilla 论文，损失函数如下：

```text
L(N, D) = A / N^α + B / D^β + E
```

- `N` = 参数数量（非嵌入层参数）。  
- `D` = 训练令牌数量。  
- `α ≈ 0.34`，`β ≈ 0.28`（大致对称）。  
- `E ≈ 1.69`，不可降低的损失下限。  
- `A ≈ 406`，`B ≈ 411`。  

两个项随着扩展相互制衡。在固定计算量（C = 6ND）时，对 `N` 求导并解方程：

```text
N_opt ≈ 0.6 × (C/6)^0.5
D_opt ≈ 0.6 × (C/6)^0.5
D_opt / N_opt ≈ 20
```

计算最佳点：每参数约 20 个令牌。

### 为什么要过度训练

Chinchilla 最优点是在每单位训练 FLOP 上最小化训练损失。但训练成本只付出一次，推理成本则持续。

对于每月处理万亿个令牌的聊天机器人来说，推理成本主导总成本。Llama 的策略是：模型小，训练时间长。8B 参数、15T 令牌训练极度推理优化：

- 可部署在消费级 GPU 上。  
- 延迟远低于 70B 的 Chinchilla 最优模型。  
- 质量对于大多数任务足够高。  

DeepMind 2024 年论文（“过度训练是新的最优”）对此进行了形式化分析。对于推理主导的工作负载，合适的比例介于每参数 100–500 个令牌，具体视服务规模而定。

### 突现与平滑性

有说法认为某些能力（算术、复杂推理、链式思维）会在某个规模“突然出现”。

Schaeffer 等人（2023）认为这是一种测量假象：所谓突现的指标用的是不连续的评分方式（精确匹配、阈值准确率），掩盖了底层 logits 的平滑提升。连续指标（交叉熵）显示出平滑曲线。

2026 年的共识是：连续损失预测更可靠。基准跳跃多半是评分系统造成的。预算规划应基于连续指标。

### 2026 年图景

规模定律依然适用，但：

| 因素 | 变化点 |
|--------|-------------|
| 数据质量 | 筛选“优质”令牌（如 Phi 风格）可使曲线有效计算量改变超过 2 倍 |
| MoE（专家混合模型） | 总参数和激活 FLOPs 解耦；采用激活 FLOPs 的规模定律 |
| 后训练阶段 | 一些能力（如指令跟随、编码）更依赖 SFT（监督微调）和 RLHF（强化学习人类反馈）而非预训练 |
| 多模态 | 图像和文本令牌共同扩展；按模态分曲线 |
| 合成数据 | 模型生成训练数据；有效计算量可以复合增长 |

Muon 优化器（Kimi Moonlight，2024）对应相同数据带来约 2 倍有效计算增益。部分 2026 年训练任务默认使用 Muon。只改变规模定律的绝对常数，不改变曲线形状。

## 实现

参见 `code/main.py`。我们实现 Chinchilla 损失公式，并求解每个计算预算下的计算最优 `(N, D)`。

### 第1步：Chinchilla 损失

```python
def chinchilla_loss(N, D, A=406.4, B=410.7, alpha=0.34, beta=0.28, E=1.69):
    return A / N ** alpha + B / D ** beta + E
```

在固定 `C = 6ND` 下，绘制 `(N, D)` 上的等高线，找到最小值。

### 第2步：计算最优前沿

针对 `1e17` 到 `1e25` FLOPs 的计算预算，找到满足 `6ND = C` 且损失最小的 `(N, D)`。验证比值 `D/N ≈ 20`。

### 第3步：过度训练成本

计算训练一个比最优小 10 倍（N 为最优的 1/10，D 为最优的 10 倍）模型时额外付出的损失。并报告以减少推理 FLOPs（与 N 成正比）换取的节省。

### 第4步：与真实模型对比

输入 GPT-3、Chinchilla、Llama 3 8B、DeepSeek-V3（活跃参数等）已知的 `(N, D)`，比较预测损失与公开数据损失。

## 使用指南

你很可能不会自己训练前沿模型。但规模定律告诉你：

1. **你的微调数据是否足够。** 如果你任务专用数据令牌数低于基础模型参数数的 20 倍，预计在某个损失下限会饱和。  
2. **是否应该选更大基础模型。** 如果预算花费全在推理，优先选择更小但训练更充分的模型。  
3. **收益递减点。** 超过 Chinchilla 最优的 1000 倍时，交叉熵损失的变化多为噪声。  

**2026 年研究方向：**

- **数据受限阶段。** 网络上高质量令牌数量有限（过滤后约 5–10 万亿英文令牌）。前沿预训练逼近天花板。合成数据、多语种、多模态和 RLHF 微调是未来杠杆。  
- **计算放大技巧。** Muon 优化器、MoE、更优数据筛选——均改变绝对常数，不触及渐近曲线。  
- **强化学习规模定律。** 未解问题。早期证据显示 RL 样本呈幂律分布，但指数远异于预训练。

## 关键词

| 术语 | 说法 | 实际含义 |
|------|-------|----------|
| Parameters（N） | “模型规模” | 非嵌入参数数量；决定模型容量。 |
| Tokens（D） | “训练数据” | 见过的训练令牌数量；决定参数的利用程度。 |
| Compute（C） | “花费 FLOPs” | 标准 Transformer（Transformer 架构）大约为 `6 × N × D`。 |
| Chinchilla-optimal | “D/N ≈ 20” | 最小化每单位预训练 FLOP 损失的比例。 |
| Over-training | “超过 Chinchilla” | 花费额外训练 FLOPs 来节省推理 FLOPs；D/N 远大于 20。 |
| Irreducible loss | “损失下限” | 规模定律中的 `E` 项；数据本身的熵。 |
| Emergent capability | “规模突现” | 多为评分系统假象；连续损失表现平滑。 |
| Effective compute | “训练效率倍率” | 更优数据、优化器、架构提升 FLOP 利用率。 |
