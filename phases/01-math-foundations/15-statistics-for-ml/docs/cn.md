# Statistics for Machine Learning（机器学习中的统计学）

> 统计学是你判断模型是真正有效还是侥幸成功的方法。

**类型：** Build  
**语言：** Python  
**先决条件：** Phase 1，第06课（概率与分布）、07课（贝叶斯定理）  
**时间：** 约120分钟

## 学习目标

- 从头计算描述性统计、Pearson/Spearman相关系数和协方差矩阵
- 执行假设检验（t检验，卡方检验）并正确解释p值和置信区间
- 使用bootstrap重采样构造任意指标的置信区间，无需分布假设
- 使用效应大小测量区分统计显著性与实际显著性

## 问题描述

你训练了两个模型。模型A在测试集上的得分是0.87，模型B是0.89。你部署了模型B。三周后，生产指标变差了。发生了什么？

模型B实际上并没有比模型A更好。0.02的差距是噪声。要么测试集太小，要么方差太大，或两者兼而有之。你推出了“伪装成改进的随机性”。

这种情况经常发生。Kaggle排行榜波动，论文无法复现，基于几百个样本就判定优劣的A/B测试。根本原因始终不变：有人跳过了统计学。

统计学为你提供区分信号与噪声的工具。它告诉你差异是否真实，你应该有多大信心，以及在信任结果前需要多少数据。每个机器学习流水线、每次模型对比、每个实验都需要统计学。没有它，你只能猜测。

## 基本概念

### 描述性统计：总结你的数据

在建模之前，你需要了解数据的基本形态。描述性统计将数据集压缩成几个数字，捕捉其形态。

**集中趋势测度** 回答“中间在哪里？”

```text
均值（Mean）：所有值之和 / 数量
        mu = (1/n) * sum(x_i)

中位数（Median）：排序后的中间值
        对异常值有鲁棒性。如果你有[1, 2, 3, 4, 1000]，均值是202，
        但中位数是3。

众数（Mode）：最常见的值
        对分类数据有用。对连续数据很少有信息量。
```

均值是平衡点。中位数是中间位置。当它们不一致时，分布是偏斜的。收入分布的均值远大于中位数（亿万富翁造成的右偏）。训练时损失分布均值通常远小于中位数（容易样本的左偏）。

**离散程度测度** 回答“数据有多分散？”

```text
方差（Variance）：与均值的平均平方偏差
            sigma^2 = (1/n) * sum((x_i - mu)^2)

标准差（Standard deviation）：方差的平方根
                     sigma = sqrt(sigma^2)
                     与数据单位相同，更易解释。

极差（Range）：最大值 - 最小值
            对异常值敏感，几乎很少单独使用。

四分位距（IQR）：Q3 - Q1（四分位间距）
            中间50%数据的范围。
            对异常值有鲁棒性。用于箱型图和异常值检测。
```

**百分位数** 将排序数据分成100等份。第25百分位数（Q1）表示25%的值低于该点。第50百分位数是中位数。第75百分位数是Q3。

```text
针对延迟监控：
  P50 = 中位延迟        （典型用户体验）
  P95 = 第95百分位      （较差但非最坏情况）
  P99 = 第99百分位      （尾延迟，通常是中位数的10倍）
```

在机器学习中，你关心推理延迟、预测置信度分布和误差分布的百分位数。平均误差很低但P99误差极差的模型，对于安全关键应用可能无用。

**样本统计量与总体统计量。** 从样本计算方差时，除以 (n-1) 而不是 n。这是贝塞尔校正，补偿样本均值不是总体真实均值的事实。除以 n 会系统性低估真实方差。除以 (n-1) 可以得到无偏估计。

```text
总体方差：     sigma^2 = (1/N) * sum((x_i - mu)^2)
样本方差：     s^2     = (1/(n-1)) * sum((x_i - x_bar)^2)
```

实践中：如果 n 很大（几千样本），差异可忽略；如果 n 很小（几十样本），差异显著。

### 相关性：变量如何一起变化

相关性度量两个变量之间线性关系的强度和方向。

**Pearson相关系数** 衡量线性关联：

```text
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1: 完美正线性关系
r = -1: 完美负线性关系
r =  0: 无线性关系（但可能存在非线性关系）

范围：[-1, 1]
```

Pearson假设关系线性且变量近似正态分布。它对异常值敏感，一个极端点就能将 r 从0.1拖拉到0.9。

**Spearman等级相关** 衡量单调关系：

```text
1. 将每个值替换为排名（1, 2, 3, ...）
2. 对排名计算Pearson相关

Spearman能捕捉任何单调关系，不仅仅是线性。
如果 y = x^3，Pearson相关是 r < 1，但Spearman秩相关是 rho = 1。
```

**何时使用：**

```text
Pearson:    两变量都是连续且近似正态分布，
            关注线性关系，
            无极端异常值。

Spearman:   有序数据（排名、评分），
            数据非正态，
            关系单调但非线性，
            存在异常值。
```

**黄金法则：** 相关性不代表因果关系。冰淇淋销量和溺水人数相关，因为二者夏季都会上升。模型准确率和参数数量相关，但增加参数并不一定提升准确率（参见：过拟合）。

### 协方差矩阵

两个变量的协方差度量它们的共同变化程度：

```text
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0:  X 和 Y 倾向同时增加
Cov(X, Y) < 0:  X 增加时，Y 倾向减少
Cov(X, Y) = 0:  无线性共变
```

对于 d 个特征，协方差矩阵 C 是一个 d×d 矩阵，其中 C[i][j] = Cov(feature_i, feature_j)。对角线元素 C[i][i] 是各特征的方差。

```text
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

性质：
  - 对称：C[i][j] = C[j][i]
  - 半正定：所有特征值 >= 0
  - 对角线为方差
  - 非对角线为协方差
```

**与PCA的关系。** PCA特征分解协方差矩阵。特征向量是主成分（最大方差方向），特征值告诉你每个成分捕获的方差大小。这正是第10课讲的内容，现在你理解为什么协方差矩阵是分解的正确对象：它编码了所有变量两两之间的线性关系。

**与相关矩阵的关系。** 相关矩阵是标准化变量（除以标准差后）的协方差矩阵。相关性归一化了协方差，使所有值都在[-1, 1]区间内。

### 假设检验

假设检验是一个在不确定性下做出决策的框架。你从一个假设出发，收集数据，并判断数据是否符合该假设。

**基本设定：**

```text
原假设（H0）：通常为“无效应”的默认假设
备择假设（H1）：你试图证明的假设

示例：
  H0：模型A和模型B的准确率相同
  H1：模型B的准确率高于模型A
```

**p值** 是在假设H0成立条件下，观察到或更极端数据的概率。它不是H0成立的概率。这是统计学中最常见的误解。

```text
p值 = P（观察到这么极端的数据 | H0为真）

如果p值 < alpha（通常0.05）：
    拒绝H0。结果“统计显著”。
如果p值 >= alpha：
    未拒绝H0。证据不足。
    这不代表H0为真。
```

**置信区间** 给出参数的合理取值范围：

```text
均值的95%置信区间：
    x_bar +/- z * (s / sqrt(n))

其中 z = 1.96 对应95%置信度

解释：如果重复该实验多次，95%的置信区间会包含真实均值。这不意味着
在这个具体区间里真实均值有95%的概率。
```

置信区间的宽度表示精度。宽区间表明不确定性大。窄区间表明估计精确（但若数据有偏差，不一定准确）。

### t检验

t检验比较均值，有多种类型。

**单样本t检验：**总体均值是否与假设值不同？

```text
t = (x_bar - mu_0) / (s / sqrt(n))

自由度 = n - 1
```

**双样本t检验（独立样本）：** 两个组均值是否不同？

```text
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

这是Welch的t检验，不假设方差相等。
除非有特别理由，否则优先使用Welch检验。
```

**配对t检验：** 当测量成对出现时（同一模型在相同数据切分上评估）：

```text
对每对计算 d_i = x_i - y_i
然后对 d_i 值做单样本t检验，检验均值是否等于0
```

在机器学习中，配对t检验很常用：你用同样的10折交叉验证分别跑两个模型，对比每折得分。

### 卡方检验（Chi-squared Test）

卡方检验检查观察频数是否与期望频数相符。适用于分类数据。

```text
chi^2 = sum((observed - expected)^2 / expected)

示例：语言模型输出在分类上的分布是否匹配训练分布？

类别       观察值     期望值
正面       120        100
负面        80        100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

自由度1时，chi^2=8对应p < 0.005，差异显著。
```

### 机器学习模型的A/B测试

机器学习中的A/B测试与网页A/B测试不同，模型对比有特殊挑战：

```text
1. 相同测试集： 两个模型必须在相同数据上评估。
                  不同测试集对比毫无意义。

2. 多指标：    仅凭准确率不足。需要关注准确率、
                召回率、F1分数、延迟、公平性指标。

3. 方差估计：  用交叉验证或bootstrap估计指标的方差，
                不只看点估计。

4. 数据泄露：  如果测试集在模型选择中被使用，
                则对比有偏。需保留最终测试集。
```

**流程：**

```text
1. 定义指标和显著性水平（alpha=0.05）
2. 在相同的k折交叉验证切分上运行两个模型
3. 收集配对得分：[(a1, b1), (a2, b2), ..., (ak, bk)]
4. 计算差值：d_i = b_i - a_i
5. 对差值执行配对t检验
6. 判断平均差是否显著不等于0
7. 计算平均差的置信区间
8. 计算效应大小（Cohen's d）判断实际意义
```

### 统计显著性 与 实际显著性

一个结果可能在统计学上显著，但在实际中毫无意义。数据量足够大时，即使是微不足道的差异也会变得统计显著。

```text
示例：
  模型A准确率：0.9234
  模型B准确率：0.9237
  测试样本数 n = 1,000,000
  p值 = 0.001

统计显著？是的。
实际显著？0.03%的提升不足以抵消部署新模型的
工程成本。
```

**效应大小（Effect size）** 量化差异的大小，与样本量无关：

```text
Cohen's d = (mean_1 - mean_2) / pooled_std

d = 0.2：小效应
d = 0.5：中等效应
d = 0.8：大效应
```

总是同时报告 p 值和效应大小。p 值告诉你差异是否真实。效应大小告诉你差异是否重要。

### 多重比较问题

当你测试很多假设时，某些结果会“偶然显著”。如果你以 alpha = 0.05 测试 20 个项目，即使没有真实差异，也会期望出现 1 个假阳性。

```text
P(至少一个假阳性) = 1 - (1 - alpha)^m

m = 20 次测试，alpha = 0.05：
P(假阳性) = 1 - 0.95^20 = 0.64

你有 64% 的概率出现至少一个假阳性。
```

**Bonferroni 校正：** 将 alpha 除以测试次数。

```text
调整后的 alpha = alpha / m = 0.05 / 20 = 0.0025

只有当 p 值 < 0.0025 才拒绝原假设 H0。
保守但简单。适用于测试独立的情况。
```

在机器学习中，当你对多个指标比较模型、测试多个超参数配置，或者在多个数据集上评估时，这一点尤为重要。

### 自助法（Bootstrap）方法

自助法通过有放回地重采样你的数据来估计统计量的抽样分布。无需对底层分布做假设。

**算法：**

```text
1. 你有 n 个数据点
2. 有放回地抽取 n 个样本（某些点会出现多次，某些点可能没出现）
3. 在这个自助样本上计算统计量
4. 重复 B 次（通常 B = 1000 至 10000）
5. 这些自助统计量的分布逼近
   统计量的抽样分布
```

**自助置信区间（百分位法）：**

```text
对 B 个统计量排序
95% 置信区间 = [第 2.5 百分位数, 第 97.5 百分位数]
```

**为何自助法对机器学习重要：**

```text
- 测试集准确率是点估计。自助法提供置信区间。
- 无法假设指标分布是正态的（尤其是 AUC，F1，precision at k）。
- 自助法适用于任何统计量：中位数，两均值之比，两模型 AUC 差异等。
- 不需要封闭形式公式。
```

**用于模型比较的自助法：**

```text
1. 获得模型 A 和模型 B 在相同测试集上的预测结果
2. 每次自助迭代：
   a. 有放回抽取测试索引
   b. 计算 metric_A 和 metric_B
   c. 保存 diff = metric_B - metric_A
3. 差异的 95% 置信区间：
   [diffs 的第 2.5 百分位数，diffs 的第 97.5 百分位数]
4. 若置信区间不包含 0，差异显著
```

这比配对 t 检验更稳健，因为它不做分布假设。

### 参数检验 与 非参数检验

**参数检验（Parametric tests）** 假设特定分布（通常是正态）：

```text
t检验：假设数据正态分布（或样本大到 CLT 生效）
方差分析（ANOVA）：假设正态性且方差齐性
Pearson相关：假设双变量正态分布
```

**非参数检验（Non-parametric tests）** 不做分布假设：

```text
Mann-Whitney U：两组比较（替代独立样本 t 检验）
Wilcoxon 符号秩检验：配对数据比较（替代配对 t 检验）
Spearman ρ：基于秩的相关（替代 Pearson）
Kruskal-Wallis：多组比较（替代 ANOVA）
```

**何时使用非参数检验：**

```text
- 小样本（n < 30）且数据明显非正态
- 有序数据（评级、排名）
- 存在无法剔除的异常值
- 偏态分布
```

**何时使用参数检验：**

```text
- 大样本量（CLT 使检验统计量近似正态）
- 数据大致对称且无极端异常值
- 拥有更强的统计功效（更容易检测真实差异）
```

在机器学习实验中，通常样本量较小（如 5 或 10 折交叉验证），所以像 Wilcoxon 符号秩检验这样的非参数检验通常比 t 检验更合适。

### 中心极限定理（CLT）的实际意义

CLT 表明，样本均值的分布趋近于正态分布，且独立于总体分布形态，条件是样本容量 n 足够大。

```text
若 X_1, X_2, ..., X_n 独立同分布，均值为 mu，方差为 sigma^2：

    X_bar ~ Normal(mu, sigma^2 / n)    当 n -> 无穷

在大多数情况下 n >= 30 足够。
对于高度偏斜的分布，可能需要 n >= 100。
```

**这对机器学习的意义：**

```text
1. 为聚合指标的置信区间和 t 检验提供理论依据
2. 解释为何交叉验证的多折平均即便每折波动很大，整体估计仍稳定
3. 小批量梯度下降有效，因为小批量的梯度均值逼近真实梯度（CLT 的体现）
4. 集成方法：多个模型预测平均，比单模型更稳定
```

**CLT 不会做的事：**

```text
- 不会让你的数据变得正态。它让样本均值变正态。
- 不适用于具有无限方差的重尾分布（如柯西分布）。
- 不适用于依赖数据（如未处理时间序列）。
```

### 机器学习论文中的常见统计错误

1. **在训练集上测试。** 必然过拟合。务必保留模型训练未见过的数据。

2. **没有置信区间。** 报告单一准确率且无不确定性，结果不可复现也无法验证。

3. **忽视多重比较。** 测试 50 个配置然后报告最优，没有做校正，虚假阳性率升高。

4. **混淆统计显著性和实际显著性。** p 值 0.001 的 0.01% 准确率提升无意义。

5. **在不平衡数据上用准确率。** 99% 负样本数据集上 99% 准确率说明模型没学到东西。应使用精确率、召回率、F1、AUC。

6. **挑选指标报告。** 只报告模型表现最好的指标。诚实评估应报告所有相关指标。

7. **训练/测试分割信息泄漏。** 先归一化后分割，或用未来数据预测过去数据。

8. **小测试集无方差估计。** 使用 100 个样本评估声称 2% 提升，其实不过是噪声。

9. **假设数据独立性失败。** 同一患者的多张医学影像、同文档多句子，组内观察相关。

10. **p 值操纵（p-hacking）。** 不断换测试、子集、排除标准直到 p < 0.05。结果是搜索造成的假象。

## 关键词汇

| 术语 | 释义 |
|---|---|
| 均值（Mean） | 值的总和除以数量。对异常值敏感。 |
| 中位数（Median） | 排序数据的中间值。对异常值稳健。 |
| 标准差（Standard deviation） | 方差的平方根。以原始单位衡量数据散布。 |
| 百分位数（Percentile） | 低于该值的数据所占百分比。 |
| 四分位间距（IQR） | 四分位距。Q3 减 Q1。中间 50% 数据的范围。 |
| Pearson 相关 | 衡量两变量线性关系。范围 [-1, 1]。 |
| Spearman 相关 | 基于秩的单调关联测量。 |
| 协方差矩阵 | 所有特征两两协方差构成的矩阵。 |
| 原假设（Null hypothesis） | 无效应或无差异的默认假设。 |
| p 值（p-value） | 在原假设为真时，观察到如此极端数据的概率。 |
| 置信区间（Confidence interval） | 参数在给定置信水平下的合理取值区间。 |
| t检验（t-test） | 检验均值是否显著不同。用 t 分布。 |
| 卡方检验（Chi-squared test） | 检验观察频数是否与预期频数不同。 |
| 效应大小（Effect size） | 差异大小，与样本量无关。Cohen's d 常用。 |
| Bonferroni 校正 | 将显著性阈值除以测试次数，控制假阳性。 |
| 自助法（Bootstrap） | 有放回采样估计抽样分布。 |
| 第一类错误（Type I error） | 假阳性。原假设为真却被拒绝。 |
| 第二类错误（Type II error） | 假阴性。原假设为假但未被拒绝。 |
| 检验功效（Statistical power） | 正确拒绝假原假设的概率，等于 1 减第二类错误率。 |
| 中心极限定理（Central limit theorem） | 样本均值分布随着样本量增大收敛于正态分布。 |
| 参数检验（Parametric test） | 假设数据遵循特定分布（通常正态）。 |
| 非参数检验（Non-parametric test） | 不做分布假设，基于秩或符号。 |
