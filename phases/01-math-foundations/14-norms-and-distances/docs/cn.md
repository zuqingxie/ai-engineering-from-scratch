## 学习目标

- 从零实现 L1、L2、余弦、Mahalanobis、Jaccard 和编辑距离函数  
- 为给定的机器学习任务选择合适的距离度量并解释为何其他方法不适用  
- 将 L1 和 L2 范数与 LASSO（套索回归）和 Ridge（岭回归）正则化及其几何约束区域连接起来  
- 演示相同数据集在不同距离度量下产生的不同最邻近点  

## 问题描述

你有两个向量。可能是词嵌入（word embeddings），可能是用户画像，也可能是像素数组。你需要知道：它们相距多近？

答案完全取决于你选择的距离函数。两个数据点在一种度量下可能是最近邻，在另一种度量下却相距甚远。你的 KNN 分类器、推荐引擎、向量数据库、聚类算法、损失函数——它们都依赖于这个选择。选错了模型就优化了错误的目标。

没有通用的最佳距离。L2 适合空间数据；余弦相似度主导自然语言处理（NLP）；Jaccard 处理集合；编辑距离处理字符串；Mahalanobis 考虑相关性；Wasserstein 用于概率质量转移。每种距离都编码了对“相似”意义的不同假设。

本课从零构建每一种主要的距离函数，展示它们的适用场景，并演示相同数据在不同度量下产生完全不同的最近邻。

## 核心概念

### 范数（Norms）：测量向量大小

范数测量向量的“大小”。所有两向量间的距离函数都可以写作它们差的范数：d(a, b) = ||a - b||。因此理解范数就是理解距离。

### L1 范数（曼哈顿距离 Manhattan distance）

L1 范数是所有分量绝对值之和。

```text
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

它被称为曼哈顿距离，因为它测量你在城市网格中只能沿轴线移动的步行距离，没有斜线。

```text
点 A = (1, 1)
点 B = (4, 5)

L1 距离 = |4-1| + |5-1| = 3 + 4 = 7

在网格上，你向东走3个街区，向北走4个街区。
```

L1 适用场景：
- 高维稀疏数据（文本特征、独热编码 one-hot encoding）
- 需要对异常值具有鲁棒性的情况（单个巨大差异不会主导）
- 特征选择问题（L1 正则化促使稀疏性）

与 L1 正则化（LASSO）连接：在损失函数中加入 ||w||_1 惩罚权重绝对值之和，将推动小权重变为零，实现自动特征选择。L1 惩罚产生钻石形的约束区域，钻石的角落位于坐标轴上，意味着部分权重为零。

与损失函数的连接：平均绝对误差（MAE）是预测值与目标值之间的平均 L1 距离。它线性惩罚所有误差，比均方误差（MSE）更能抵抗异常值。

### L2 范数（欧氏距离 Euclidean distance）

L2 范数是直线距离。是各分量平方和的平方根。

```text
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

这是你在几何课上学的距离，n 维空间的毕达哥拉斯定理。

```text
点 A = (1, 1)
点 B = (4, 5)

L2 距离 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

斜穿网格的直线距离。
```

L2 适用场景：
- 低到中维连续数据  
- 特征尺度相当时  
- 物理距离数据（空间数据、传感器读取）  
- 像素级图像相似度  

与 L2 正则化（岭回归 Ridge）连接：在损失函数中加入 ||w||_2^2 惩罚大权重。不同于 L1，L2 不推零权重，而是按比例缩小所有权重。L2 惩罚产生圆形约束地区，没有角落出现于坐标轴上，权重变小但很少变为零。

与损失函数的连接：均方误差（MSE）是平方的 L2 距离的平均。平方项加重对大误差的惩罚。

```text
MAE (L1 损失):  |y - y_hat|         线性惩罚。对异常值鲁棒。
MSE (L2 损失):  (y - y_hat)^2       二次惩罚。对异常值敏感。
```

### Lp 范数：通用范数族

L1 和 L2 是 Lp 范数的特殊情况：

```text
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

不同 p 值对应不同形状的“单位球”(所有距原点距离为1的点集合)：

```text
p=1:    钻石形状      （角落在坐标轴上）
p=2:    圆形/球形      （通常的圆球）
p=3:    超椭圆形       （圆角方形）
p=inf:  方形/超立方体  （沿坐标轴平坦的边）
```

### L-无穷范数（Chebyshev 距离）

当 p 趋近无穷大时，Lp 范数收敛为最大绝对分量。

```text
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

两点间距离由它们最大的单个分量差决定，其他维度被忽略。

```text
点 A = (1, 1)
点 B = (4, 5)

L-inf 距离 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

L-无穷适用场景：
- 任何单一维度中的最大偏差关乎整体时  
- 棋盘游戏（国际象棋中的国王移动类似于 L-infinity：任何方向一步成本为1）  
- 制造公差（每个维度都必须符合规范）  

### 余弦相似度与余弦距离

余弦相似度测量两个向量间的夹角，忽略了它们的大小。

```text
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

取值范围是 -1（方向相反）到 +1（方向相同）。垂直向量的余弦相似度为 0。

余弦距离则转换为距离度量：cosine_distance = 1 - cosine_similarity。范围从 0（完全相同方向）到 2（方向相反）。

```text
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

余弦相似度为何主导 NLP 和嵌入：文本中，文档长度不应影响相似度。一篇关于猫的文章如果是另一篇的两倍长，它们仍然是“相似”的。余弦相似度忽略了长度（大小），只关注方向。两个词分布相同但长度不同的文档向量指向同一方向，余弦相似度为 1.0。

余弦相似度适用场景：
- 文本相似度（TF-IDF 向量、词嵌入、句子嵌入）  
- 任何幅度是噪声、方向是信号的领域  
- 推荐系统（用户偏好向量）  
- 嵌入搜索（向量数据库几乎总是使用余弦或点积）  

### 点积相似度 VS 余弦相似度

两个向量的点积为：

```text
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(angle)
```

余弦相似度是点积除以两者大小的归一化。当两个向量已经单位归一（长度为1）时，点积和余弦相似度相同。

```text
如果 ||a|| = 1 和 ||b|| = 1:
    a . b = cos(a 和 b 之间的夹角)
```

不同处在于：点积包含幅度信息。幅度大的向量会得到更高的点积分数。这在某些检索系统中很重要，比如想让“热门”项排名更靠前。幅度体现了隐含的质量或重要性信号。

```text
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

两者都能反映方向，但点积也反映大小。
```

实践中：
- 当你只关注方向相似时使用余弦相似度  
- 当幅度包含有意义信息时使用点积  
- 许多向量数据库（Pinecone，Weaviate，Qdrant）允许选择两者之一  
- 如果嵌入已经 L2 归一，二者效果相同  

### Mahalanobis 距离

欧氏距离（L2）对所有维度一视同仁。但如果特征相关或尺度不同，L2 会导致误导。

Mahalanobis 距离考虑数据的协方差结构。

```text
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

其中 S 是数据的协方差矩阵。

直观理解：Mahalanobis 距离先对数据进行去相关和归一化（whitening），然后再在变换后的空间计算 L2 距离。如果 S 是单位矩阵（特征独立且方差为1），Mahalanobis 距离退化为欧氏距离。

```text
例如：身高和体重有相关性。
身高6英尺2寸，体重180磅是正常的。
身高5英尺0寸，体重180磅则不常见。

欧氏距离可能认为二者离均值距离相似。
而 Mahalanobis 距离正确识别第二者为异常值，
因为它考虑了身高和体重的相关性。
```

Mahalanobis 距离适用场景：
- 异常值检测（离均值 Mahalanobis 距离大的为异常点）  
- 特征尺度和相关性不同的分类  
- 有足够数据估计协方差矩阵时  
- 制造工艺质量控制（多元过程监测）  

### Jaccard 相似度（用于集合）

Jaccard 相似度量两个集合的重叠程度。

```text
J(A, B) = |A ∩ B| / |A ∪ B|
```

取值范围是 0（无重叠）到 1（集合相同）。Jaccard 距离 = 1 - Jaccard 相似度。

```text
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

交集 = {cat, fish}         大小 = 2
并集 = {cat, dog, fish, bird, snake}  大小 = 5

Jaccard 相似度 = 2/5 = 0.4
Jaccard 距离 = 0.6
```

Jaccard 适用场景：
- 标签、类别或特征集合的比较  
- 基于词存在（非频率）的文档相似度  
- 近似重复检测（MinHash 是 Jaccard 的近似）  
- 二进制特征向量（存在/不存在数据）  
- 语义分割模型评估（交并比 Intersection over Union = Jaccard）  

### 编辑距离（Levenshtein 距离）

编辑距离计算将一个字符串转换成另一个字符串所需的最少单字符操作次数，操作包括：插入、删除或替换。

```text
"kitten" -> "sitting"

kitten -> sitten  (替换 k -> s)
sitten -> sittin  (替换 e -> i)
sittin -> sitting (插入 g)

编辑距离 = 3
```

用动态规划计算。填充一个矩阵，矩阵中 (i, j) 处记录字符串 A 的前 i 个字符与字符串 B 的前 j 个字符的编辑距离。

```text
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

编辑距离适用场景：
- 拼写检查和纠正  
- DNA 序列比对（带权重操作）  
- 模糊字符串匹配  
- 整理杂乱文本数据的去重

### KL散度（不是距离，但用作距离）

KL散度衡量一个概率分布与另一个概率分布的差异。在第09课中涵盖，但因为人们把它当作“距离”使用，尽管它不是距离，所以放在这里讨论。

```text
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

关键属性：KL散度**不对称**。

```text
D_KL(P || Q) != D_KL(Q || P)
```

这意味着它不满足距离度量的基本要求。它也不满足三角不等式。它是发散度（divergence），不是距离。

前向KL（D_KL(P || Q)）是“均值寻求”：Q试图覆盖P的所有模式。  
反向KL（D_KL(Q || P)）是“模式寻求”：Q聚焦于P的单一模式。

KL散度出现的场景：  
- 变分自编码器（VAE）（ELBO中的KL项推动潜在分布靠近先验）  
- 知识蒸馏（学生试图匹配教师的分布）  
- 人类反馈强化学习（RLHF）（KL惩罚保持微调模型接近基础模型）  
- 策略梯度方法（约束策略更新）

### Wasserstein距离（地球移动者距离）

Wasserstein距离衡量将一个概率分布转变成另一个概率分布所需的最小“工作量”。可以把它理解为：如果一个分布是一堆泥土，另一个是一个洞，需要挪多少泥土、多远才能填满洞。

```text
W(P, Q) = inf over all transport plans gamma of E[d(x, y)]
```

对于一维分布，简化成累积分布函数绝对差的积分：

```text
W_1(P, Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

为什么Wasserstein重要：  
- 它是真正的度量（对称，满足三角不等式）  
- 即使分布不重叠时也能提供梯度（KL散度会趋向无穷大）  
- 这一性质使其成为Wasserstein GAN（WGAN）的核心，解决了原始GAN训练不稳定的问题

```text
无重叠的分布：

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL散度：无穷大（对零取对数）  
Wasserstein：4（移动全部质量4个桶距离）

Wasserstein给出有意义的梯度。KL不行。
```

何时使用Wasserstein：  
- GAN训练（WGAN，WGAN-GP）  
- 比较可能无重叠的分布  
- 最优传输问题  
- 图像检索（比较颜色直方图）

### 不同任务需要不同距离的原因

| 任务               | 最佳距离            | 原因                                                 |
|--------------------|--------------------|----------------------------------------------------|
| 文本相似度         | 余弦相似度 Cosine   | 向量大小是噪声，方向才承载语义                          |
| 图像像素比较       | L2                 | 空间关系重要，特征在可比尺度上                          |
| 稀疏高维特征       | L1                 | 鲁棒，不放大罕见的大差异                              |
| 集合重叠（标签、类别） | Jaccard            | 数据天然是集合而非向量                                 |
| 字符串匹配         | 编辑距离 Edit distance | 操作对应人类编辑直觉                                  |
| 离群点检测         | Mahalanobis        | 考虑特征相关性和尺度                                  |
| 比较分布           | KL散度             | 衡量用Q编码P时的信息损失                               |
| GAN训练            | Wasserstein        | 即使分布不重叠也能提供梯度                            |
| 嵌入向量（向量数据库） | 余弦相似度或点积 Dot product | 嵌入训练编码语义在方向上                              |
| 推荐系统           | 点积 Dot product   | 向量大小可编码流行度或置信度                           |
| DNA序列            | 加权编辑距离        | 替换成本因核苷酸对而异                                |
| 制造质检           | L-无穷范数 L-infinity | 任何维度的最大偏差最关键                               |

### 与损失函数的关联

损失函数是对预测与目标应用的距离函数。

```text
损失函数          使用的距离          行为特征
MSE               L2平方              重罚大误差
MAE               L1                  所有误差一视同仁
Huber损失         大误差用L1，       兼具两者优点：对异常值鲁棒，零附近梯度平滑
                  小误差用L2        
交叉熵            KL散度              衡量分布差异
铰链损失(Hinge)   max(0, margin - d)  只惩罚低于margin的情况
三元组损失         L2（通常）          拉近正样本，推远负样本
对比损失           L2                  相似对靠近，不相似对超出margin
```

### 与正则化的关联

正则化在损失上添加权重范数惩罚。

```text
L1正则化（Lasso）：   loss + lambda * ||w||_1
  -> 稀疏权重。一部分权重变成精确的零。
  -> 自动特征选择。
  -> 解集有角点（零点处不可微）。

L2正则化（Ridge）：   loss + lambda * ||w||_2^2
  -> 小权重。所有权重都向零缩小。
  -> 无特征选择（不会精确为零）。
  -> 解处处光滑。

弹性网 Elastic Net：   loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> 结合L1的稀疏性和L2的稳定性。
  -> 一组相关特征共同被选中或丢弃。
```

为什么L1产生稀疏而L2不会：想象二维权重空间的约束区域。L1是菱形，L2是圆。损失函数的等高线（椭圆）更可能接触菱形的顶点（一个权重为零），而只在圆的平滑点接触，两个权重均非零。

### 最近邻搜索

每个距离函数都隐含最近邻搜索问题：给定查询点，找出数据集中距离最近的点。

在有n个点、维度为d的数据集中，精确最近邻搜索是O(n * d)复杂度。大数据集下，这太慢。

近似最近邻（ANN）算法以牺牲一些准确度换取极大加速：

```text
算法           方法                     应用场景
KD树           轴对齐空间划分           scikit-learn（低维）
球树           嵌套超球                 scikit-learn（中维）
局部敏感哈希   随机哈希投影             近重复检测
HNSW           分层可导航小世界图       FAISS、Qdrant、Weaviate
倒排文件索引 IVF    基于簇的倒排搜索       FAISS（十亿级别）
乘积量化       压缩向量，压缩空间搜索   FAISS（内存受限）
```

HNSW（Hierarchical Navigable Small World，分层可导航小世界）是现代向量数据库的主流算法。它构建多层图，每个节点连接近似最近邻。搜索从顶层（稀疏、长跳）开始，逐层到底层（密集、短跳）。

## 实用示例

最常见实用场景：在向量数据库中找到相似项。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"Top 5 most similar to item 0: {top_k}")
print(f"Similarities: {similarities[top_k]}")
```

## 关键词

| 术语                | 常见说法                | 实际含义                                               |
|---------------------|-------------------------|-------------------------------------------------------|
| 范数（Norm）         | “向量大小”              | 将向量映射到非负标量，满足三角不等式、齐次性、零向量范数为零  |
| L1范数               | “曼哈顿距离”            | 绝对分量之和。产生稀疏性，对异常值鲁棒                  |
| L2范数               | “欧氏距离”              | 分量平方和开根号，欧式空间中直线距离                     |
| Lp范数               | “广义范数”              | 绝对分量p次幂求和开p次方根。L1和L2是特殊案例             |
| L-无穷范数           | “最大范数”或“切比雪夫距离” | 最大绝对分量值。Lp范数p趋于无穷的极限                      |
| 余弦相似度（Cosine similarity） | “向量夹角”              | 两向量点积除以模长乘积，值域[-1, +1]，忽略向量长度          |
| 余弦距离（Cosine distance）   | “1减余弦相似度”         | 由余弦相似度转换为距离，范围[0, 2]                       |
| 点积（Dot product）   | “未归一化余弦”           | 分量逐乘求和。等于余弦相似度乘以各自模长                   |
| 马氏距离（Mahalanobis distance） | “相关性感知距离”          | 在用数据协方差矩阵白化（去相关且归一化）后的空间中计算的L2距离  |
| Jaccard相似度        | “集合重叠”               | 交集大小除以并集大小，适用于集合非向量                      |
| 编辑距离（Edit distance）    | “Levenshtein距离”        | 转换一个字符串到另一个所需的最小插入、删除和替换操作数       |
| KL散度（KL divergence）       | “分布间距离”            | 不是真正距离（不对称），衡量用Q编码P时的信息损失             |
| Wasserstein距离         | “地球移动者距离”          | 传输质量的最小工作量，是一个真正的度量                        |
| 近似最近邻（Approximate nearest neighbor） | “ANN搜索”               | HNSW、LSH、IVF等算法，快速找到近似最近的点                     |
| HNSW                    | “向量数据库算法”          | 分层可导航小世界图，多层图实现快速近似最近邻搜索               |
| L1正则化               | “Lasso”                 | 损失加权重L1范数，权重驱动为零（稀疏）                        |
| L2正则化               | “Ridge”或“权重衰减”       | 损失加权重平方L2范数，权重向零收缩但不产生稀疏                  |
| 弹性网（Elastic Net）    | “L1 + L2”               | 结合L1和L2正则化，较好处理相关特征组                          |
