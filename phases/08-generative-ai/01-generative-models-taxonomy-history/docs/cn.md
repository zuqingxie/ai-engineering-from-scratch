# 生成模型 — 分类法与历史

> 每个图像模型、文本模型、视频模型和 3D 模型都属于五大类之一。选错类别，你会被数学难题折磨数周。选对了，过去十二年的领域进展会清晰地呈现在你脑海中。

**类型：** 学习  
**语言：** Python  
**先修条件：** 第2阶段（机器学习基础）、第3阶段（深度学习核心）、第7·14阶段（Transformer（Transformer 架构））  
**时长：** ~45分钟

## 问题

生成模型的任务只有一个：给定从某个未知分布 `p_data(x)` 抽取的训练样本，输出看起来好像来自同一分布的新样本。无论是人脸、句子、MIDI 文件、蛋白质结构——只要你眯眼看，问题都是一样的。

难点在于 `p_data` 生活在拥有百万维空间中（一个512x512的RGB图像约有786k维度），样本位于该空间中的一条细流形上，而你可能只有1000万样本。对密度的暴力求解毫无希望。每个生成模型都是一个权衡，用一个难问题换一个稍微容易点的问题。

五个家族在过去十二年中幸存。知道每个家族做出的权衡，能告诉你它们为什么在某些任务上胜出，而在其他任务上崩塌。

## 概念

![生成模型五大类 — 按模型类别分类](../assets/taxonomy.svg)

**1. 显式密度，可计算。** 将 `log p(x)` 写成一个你实际能计算的和。自回归模型（PixelCNN、WaveNet、GPT）分解 `p(x) = ∏ p(x_i | x_<i)`。正规化流（RealNVP、Glow）将 `p(x)` 构建为简单基分布的可逆变换。优点：精确似然，训练损失清晰；缺点：自回归推理为顺序（长序列慢），流需要可逆架构（架构限制）。

**2. 显式密度，近似。** 对 `log p(x)` 做下界（ELBO），优化该下界。VAE（Kingma 2013）用编码器-解码器和变分后验。扩散模型（DDPM，Ho 2020）训练一个去噪器，隐式优化加权 ELBO。扩散是2026年图像、视频和3D的主流骨干。

**3. 隐式密度。** 完全跳过密度；学习生成器 `G(z)` 产生样本和判别器 `D(x)` 区分真伪。GAN（Goodfellow 2014）。推理快速（一遍前向），但训练不稳定。StyleGAN 1/2/3 即使在2026年仍然是固定领域照片真实感（人脸、卧室）领域的顶尖。

**4. 基于梯度 / 连续时间。** 直接学习对数密度的梯度 `∇_x log p(x)`（score）。Song & Ermon（2019）展示了打分匹配（score matching）推广了扩散为随机微分方程（SDE）。流匹配（Lipman 2023）是2024-2026年的热点：无仿真训练，路径更直，采样比DDPM快4-10倍。Stable Diffusion 3、Flux、AudioCraft 2 都用流匹配。

**5. 对离散码的基于令牌的自回归。** 用 VQ-VAE 或残差量化器把高维数据压缩成离散令牌的短序列，再用 Transformer（Transformer 架构）对令牌序列建模。Parti、MuseNet、AudioLM、VALL-E、Sora 的补丁令牌器都用这套。等同于类别1加上一个学习型分词器。

## 五问分诊

当有新生成模型论文发布，阅读方法部分前回答这五个问题：

1. **被建模的是什么？** 像素、潜变量、离散令牌、3D高斯、网格、波形？
2. **密度是显式还是隐式？** 有没有写出 `log p(x)`？
3. **采样：一次完成还是迭代进行？** 迭代通常推理更慢；一次完成一般意味着对抗或蒸馏。
4. **条件：无条件、类别、文本、图像、姿态？** 这决定损失和架构骨架。
5. **评估方式：FID、CLIP 分数、IS、人类偏好、任务准确率？** 每个都有已知的失效模式（参见第14课）。

你会在本阶段每节课都重新回答这五问，最终成为条件反射。

## 实践

本课代码是一个轻量可视化：对来自二维高斯混合的数据，用三种简易方式拟合1维混合高斯（核密度估计、离散直方图和最近样本的“类GAN”生成器），让你能在一屏看到显式密度和隐式密度的区别。

运行 `code/main.py`。它会从双峰高斯混合中抽取2000个样本，然后打印：

```text
explicit density (histogram): p(x in [-0.5, 0.5]) ≈ 0.38
approximate density (KDE):     p(x in [-0.5, 0.5]) ≈ 0.41
implicit (nearest-sample gen): 20 new samples printed, no p(x)
```

注意：前两个能回答“这个点的概率有多大？”，第三个不能。这就是将来每节课都会用到的*显式与隐式*之分。

## 应用

2026年哪个家族适合哪个任务？

| 任务 | 最佳家族 | 原因 |
|------|-------------|-----|
| 窄域的真实照片人脸 | StyleGAN 2/3 | 依旧最锐利，推理最快。 |
| 通用文本生成图像 | 潜变量扩散 + 流匹配 | SD3，Flux.1，DALL-E 3。 |
| 快速文本生成图像 | 修正流 + 蒸馏 | SDXL-Turbo，SD3-Turbo，LCM。 |
| 文本生成视频 | 扩散 Transformer + 流匹配 | Sora，Veo 2，Kling。 |
| 语音与音乐 | 基于令牌的自回归（AudioLM、VALL-E、MusicGen）或流匹配（AudioCraft 2） | 离散令牌低成本扩展。 |
| 3D场景 | 高斯点云拟合，扩散先验 | 3D-GS 用于重建，扩散用于新视角生成。 |
| 密度估计（无采样） | 流模型 | 唯一具有精确 `log p(x)` 的家族。 |
| 仿真／物理 | 流匹配，打分SDE | 直接路径，平滑向量场。 |

## 关键词

| 术语 | 大众说法 | 真实含义 |
|------|-----------------|-----------------------|
| Generative model（生成模型） | “它能生成新东西” | 学习 `p_data(x)` 的采样器，可选暴露 `log p(x)`。 |
| Explicit density（显式密度） | “你能计算它” | 模型提供闭式或可计算的 `log p(x)`。 |
| Implicit density（隐式密度） | “GAN样式” | 只有采样器——无法计算某点的 `p(x)`。 |
| ELBO | “证据下界” | `log p(x)` 的可计算下界；VAE 和扩散优化它。 |
| Score（得分） | “对数密度的梯度” | `∇_x log p(x)`；扩散和SDE模型学习该场。 |
| Manifold hypothesis（流形假设） | “数据活跃在表面上” | 高维数据集中于低维流形；降维的原因。 |
| Autoregressive（自回归） | “预测下一个部分” | 将联合分布分解为条件概率乘积。 |
| Latent（潜变量） | “压缩码” | 低维表示，解码器可重建输入。 |

## 生产注：五大类，五种推理形态

每个家族对应不同的推理服务器成本曲线。生产推理文献将大型语言模型推理分为预填充 + 解码；这里同样适用：

- **自回归（类别1和5）。** 顺序解码主导延迟；KV缓存、连续批处理和猜测解码均可用。  
- **VAE / 扩散 / 流匹配（类别2和4）。** 没有大型语言模型意义下的解码。成本 = `步数 × 每步成本`，每步成本为全分辨率潜变量上的 Transformer 或 U-Net 前向。调节参数为步数（DDIM / DPM-Solver / 蒸馏）、批量大小和精度（bf16 / fp8 / int4）。  
- **GAN（类别3）。** 一次前向。无调度，无KV缓存。TTFT≈总延迟。这也是 StyleGAN 在窄域用户体验中仍领先的原因。

论文摘要写“比扩散快”，翻译为“步数更少 × 每步相同成本”或者“步数相同 × 每步更便宜”。其他都是营销。
