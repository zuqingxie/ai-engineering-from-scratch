# Visual Autoregressive Modeling (VAR)：下一尺度预测

> 扩散模型（Diffusion models）在时间维度上迭代采样（去噪步骤）。VAR在尺度上迭代采样——它先预测一个 1x1 标记，然后是 2x2、4x4，直到最终分辨率，每个尺度都以之前尺度为条件。2024 年的论文展示了 VAR 在图像生成中匹配 GPT 风格的规模定律，并在相同计算预算下击败了 DiT。本课构建其核心机制。

**类型：** 构建  
**语言：** Python（使用 PyTorch）  
**先决条件：** 第7阶段第03课（多头注意力）、第8阶段第06课（DDPM）  
**时间：** ~90分钟

## 问题

自回归生成（Autoregressive generation）主导了语言建模，因为它有可预测的扩展性：更多计算、更多参数、更低困惑度（perplexity）、更好输出。2024年前，图像生成有两个主要自回归尝试：PixelRNN/PixelCNN（逐像素）和 DALL-E 1 / Parti / MuseGAN（基于 VQ-VAE 代码的逐标记）。

两者都存在生成顺序问题。像素和标记排列成二维网格，但自回归模型必须遵循一维栅格顺序访问。位于早期角落的像素无法知道最终图像内容。生成质量的扩展远不及 GPT 在文本上的表现，且在相同计算条件下从未达到扩散模型的质量。

VAR 通过改变生成内容解决了生成顺序问题。VAR不是逐空间预测图像标记，而是预测增加分辨率的整张图像。步骤1：预测1x1标记（整体图像“总结”）。步骤2：预测2x2标记网格（粗略特征）。步骤3：预测4x4标记网格。步骤K：预测最终 (H/8)x(W/8) 网格。

每个尺度按“尺度顺序”因果地关注所有之前尺度，同时同一尺度内并行关注。顺序问题消失：尺度 k 上的整张图像在一次 transformer 前向中生成。

## 概念

### VQ-VAE 多尺度标记器

VAR 需要一个**多尺度离散标记器**。给定图像 x，它生成一系列逐步提高分辨率的标记网格序列：

```text
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 的形状为 (1, 1)
f -> tokenize at 2x2: token grid z_2 的形状为 (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K 的形状为 (H/p, W/p)
```

每个 z_k 使用相同的码本（典型大小 4096-16384）。每个尺度的标记化不是独立的——训练目标是使得各尺度残差相加能近似重建 f：

```text
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

这是一种**残差 VQ**变体。尺度 k 捕捉尺度 1..k-1 遗漏的信息。解码器对所有尺度嵌入求和生成图像。

多尺度 VQ 标记器训练一次（类似 VQGAN）后被冻结，所有生成任务由其上的自回归模型完成。

### 下一尺度预测

生成模型是一个 transformer，能看到所有之前尺度的标记，并预测下一尺度的标记。

输入序列结构：
```text
[START, z_1 标记, z_2 标记, z_3 标记, ..., z_K 标记]
```

位置嵌入同时编码尺度索引和尺度内空间位置。注意力在尺度顺序上因果：尺度 k 的位置 (i, j) 可以关注尺度 1..k 的所有标记，以及尺度 k 内在固定位置注意力规则下的早期标记（VAR 采用固定位置注意力，无尺度内因果——尺度内所有位置并行预测）。

训练损失：在每个尺度 k 上，给定所有之前尺度的标记，预测 z_k。对离散 VQ 代码做交叉熵损失。结构与 GPT 类似，不同的是“序列”现在有尺度结构。

### 生成

推理时：
```text
生成 z_1 = 从 p(z_1) 采样                    # 1个标记
生成 z_2 = 从 p(z_2 | z_1) 采样              # 4个标记并行生成
生成 z_3 = 从 p(z_3 | z_1, z_2) 采样         # 16个标记并行生成
...
解码： f = 1..K尺度嵌入上采样求和
图像 = VAE_decoder(f)
```

对于 K=10 个尺度，生成需要 10 次 transformer 前向，每次并行生成整个尺度内所有标记——无尺度内的逐标记自回归。对于 256x256 图像，约为 10 次前向，相比 DiT 的 28-50 次。

### 下一尺度优于逐标记生成的原因

三个结构性优势：
1. **从粗到细符合自然图像统计。** 人类视觉和图像数据集都有尺度相关规律：低频结构稳定且可预测；高频细节依赖低频内容。下一尺度预测利用了此规律。
2. **尺度内并行生成。** 与 GPT 式逐标记自回归不同，VAR在一个步骤内生成完整尺度所有标记。有效生成长度为对数尺度而非线性。
3. **无生成顺序偏置。** 尺度 k 上的标记能看到尺度 k-1 全部信息，无需受“左侧”或“上方”偏好限制，早期标记不会须提前承诺。

### 规模定律

Tian 等人证明 VAR 在 ImageNet 上的 FID 指标遵循幂律缩放曲线——类似 GPT 对困惑度的表现。参数或计算翻倍，错误率稳定减半。这是首个图像生成模型如此清晰地展现这一规模定律。结果是，VAR的尺度预测对计算成本可预测，不依赖架构上的经验调参。

### 与扩散模型的关系

VAR 与扩散共用数据压缩思路：都将生成任务拆成一系列更易处理的子问题。

- 扩散：逐步加入噪声，学会一步步还原。
- VAR：逐步增加分辨率，学会预测下一尺度。

它们在生成问题上是不同维度。均得到可处理的条件分布。经验上，VAR推理更快（更少前向，且尺度内全并行），在类条件 ImageNet 竞赛中匹配或优于 DiT。文本条件 VAR（VARclip，HART）是活跃研究方向。

## 构建

在 `code/main.py`：
1. 构建一个微型**多尺度 VQ 标记器**，基于合成“图像”数据（二维高斯环）。
2. 训练**VAR风格 Transformer**预测下一尺度标记。
3. 调用 Transformer 4 次（4个尺度）进行采样并解码。
4. 验证尺度顺序训练效果，使得尺度内生成并行。

这是一个玩具实现，目的是展示尺度结构的注意力掩码和尺度内并行生成的实际工作原理。

## 练习

1. **尺度数量消融。** 训练使用 4、6、8、10 个尺度的 VAR。评估重建质量与自回归前向次数关系。尺度越多，残差越细致，质量越优但前向次数增多。
2. **码本大小。** 训练码本大小分别为 512、4096、16384 的标记器。大码本改善重建但增加预测难度。寻找拐点。
3. **尺度内并行验证。** 在训练完成的 VAR 中，量化注意力模式。尺度 k 内，模型是否关注跨尺度位置但不关注尺度内？验证掩码实现。
4. **VAR 与 DiT 的规模对比。** 在相同 ImageNet 类条件任务下，匹配参数预算（33M、130M、458M）分别训练 VAR 和 DiT，绘制 FID-计算关系图。VAR 应在各规模上超越 DiT，复现论文小规模结果。
5. **文本条件。** 扩展 VAR 输入文本嵌入（CLIP 池化向量）作为通过 adaLN 的额外条件输入，实现 HART 方案。观察文本对齐采样的 FID 提升。

## 关键术语

| 术语 | 人们说 | 实际含义 |
|------|--------|--------|
| VAR | “Visual AutoRegressive” | 基于 VQ 标记金字塔的下一尺度视觉图像生成 |
| 下一尺度预测 | “先预测粗，再细” | 模型按分辨率递增的尺度预测标记，条件为所有之前尺度标记 |
| 多尺度 VQ 标记器 | “残差 VQ” | VQ-VAE 生成 K 个不同分辨率标记网格，解码器汇总所有尺度 |
| 尺度 k | “金字塔第k级” | K 个分辨率层之一，从 k=1 的 1x1 到 k=K 的 (H/p)x(W/p) |
| 尺度内并行 | “每尺度一次前向” | 尺度 k 的所有标记在一个 transformer 前向中预测，无自回归 |
| 跨尺度因果 | “尺度顺序注意力” | 尺度 k 的标记能关注尺度 1..k 标记，但不能关注更高尺度  |
| 残差 VQ | “加法标记化” | 每个尺度标记编码前尺度残差，解码器对尺度嵌入求和 |
| VAR 规模定律 | “图像 GPT 规模” | FID 根据计算量呈幂律衰减，类似语言模型的困惑度规模行为 |
| HART | “混合 VAR + 文本” | 结合 MaskGIT 迭代解码和 VAR 尺度结构的文本条件 VAR 变体 |
| 尺度位置编码 | “(尺度, 行, 列) 三元组” | 位置编码包含尺度索引及尺度内空间坐标 |
