# 大型语言模型的差分隐私（Differential Privacy for LLMs）

> DP-SGD 仍是标准——注入噪声的梯度更新提供形式化的（ε, δ）保证。计算、内存和效用开销显著；参数高效的 DP 微调（LoRA + DP-SGD）是 2025 年的常见配置（ACM 2025）。存在两类相互矛盾的证据：基于金丝雀（canary）的成员推断攻击（membership inference attack, MIA）（Duan 等，2024）显示对语言模型的攻击成功有限；训练数据提取（Carlini 等，2021；Nasr 等，2025）则显示大量逐字记忆。解决方案（arXiv:2503.06808，2025 年 3 月）：差异在于测量的对象——插入的金丝雀与“最易提取”数据。新的金丝雀设计使基于损失的 MIA 无需阴影模型成为可能，并产生首个在真实数据和现实 DP 保证下对 LLM 的非平凡 DP 审计。替代方案包括：PMixED（arXiv:2403.15638）——通过下一词分布的专家混合实现推理时的私有预测；DP 合成数据生成（Google Research 2024）。新兴攻击：通过 LLM 反馈的差分隐私反转攻击（Differential Privacy Reversal）——置信度得分泄漏。

## 问题背景

大型语言模型（LLMs）会记忆。Carlini 等 2021 年展示了生产环境语言模型能按需逐字输出训练文本。差分隐私是正式防御方法：训练时保证输出对任何单个训练样本的影响可证明地不敏感。2024-2025 年的证据显示 DP-SGD 是必要的，但实际部署时的 ε 值可能与威胁模型不匹配。

## 概念介绍

### （ε, δ）-差分隐私

一个随机算法 M 是（ε, δ）-DP，如果对任意相差一个样本的数据集 D 和 D′ 及任何事件 S，都有：
P(M(D) ∈ S) ≤ e^ε × P(M(D′) ∈ S) + δ。

解释：输出分布在参数 ε 控制下足够接近，任何单个样本的贡献无法可靠推断，除非概率为 δ。

### DP-SGD

Abadi 等，2016 年提出。标准步骤如下：
1. 采样一个小批量数据。  
2. 计算每个样本的梯度。  
3. 将每个样本梯度裁剪到阈值 C。  
4. 将裁剪后的梯度求和并加上标准差为 σ × C 的高斯噪声。  
5. 使用含噪梯度更新参数。

隐私预算由计账器（Moments Accountant、Rényi DP 计账器）追踪。LLM 文献中的 ε 值因威胁模型、数据敏感度及效用目标而异；无通用的“安全”默认 ε。已有示范多在 ε ≈ 1–10 之间，但仅供参考，非推荐默认。较小 ε 通常意味着更大噪声，可能增加效用损失。

### LoRA + DP-SGD

对尖端模型进行完整 DP-SGD 微调成本巨大。LoRA（Hu 等，2022）将梯度更新限制于小型适配器，减少每样本梯度存储。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证适用于适配器，基础模型保持固定。

### 2024-2025 年的矛盾

两条证据线：

- **金丝雀 MIA（Duan 等 2024）。** 在训练数据中插入唯一金丝雀样本，评估成员推断攻击能否识别。报告攻击成功率有限，表明 MIA 不易。  
- **训练数据提取（Carlini 2021，Nasr 等 2025）。** 给模型前缀提示，衡量能否恢复逐字训练文本。报告记忆广泛，表明 MIA 在相关意义上容易。

2025 年 3 月解决方案（arXiv:2503.06808）：两者测量的内容不同。MIA 问“样本 e 是否在训练集中？”针对插入的金丝雀；提取问“我能恢复多少训练数据？”“最易提取”的样本才是隐私重点；金丝雀未被设计为易提取，因此低估泄露。

新的金丝雀设计，基于损失的 MIA 无需阴影模型，实现首个对真实数据和现实 DP 保证下 LLM 的非平凡 DP 审计。

### DP 训练的替代方案

- **PMixED（arXiv:2403.15638）。** 推理时的私有预测。通过专家混合分别运算下一词分布，每个专家见到训练数据子集，聚合时加入噪声以实现 DP，完全规避 DP 训练。  
- **DP 合成数据生成（Google Research 2024）。** 用 DP-SGD 微调 LoRA，采样合成数据，再用合成数据训练下游分类器。

两者都规避了完整 DP 训练的效用代价，但改变了威胁模型。

### 通过 LLM 反馈实现的差分隐私反转攻击

2025 年出现的新攻击。使用 DP 训练模型的置信度得分作为预言机，重新识别个体。即使模型输出不泄露，置信度分布也能泄露。

防御：不暴露置信度，或在暴露前截断/量化置信度。这是超越（ε, δ）-DP 训练的附加要求。

## 关键词汇

| 术语 | 俗称 | 实际含义 |
|------|-----------------|------------------------|
| DP | “（ε, δ）差分隐私” | 正式隐私定义：输出分布在相邻数据集间保持接近 |
| DP-SGD | “注入噪声的 SGD” | 梯度裁剪加高斯噪声；标准 DP 训练方式 |
| LoRA + DP-SGD | “高效私有微调” | 低秩适配器上的 DP-SGD；2025 标准配置 |
| MIA | “成员推断攻击” | 攻击判定样本是否在训练集中 |
| 金丝雀 | “插入的水印样本” | 用于测量 DP 泄露的唯一训练样本 |
| PMixED | “私有推理混合模型” | 推理时基于下一词分布的专家混合实现 DP |
| DP 反转 | “置信度泄漏攻击” | 攻击利用模型置信度作为预言机进行重新识别 |
