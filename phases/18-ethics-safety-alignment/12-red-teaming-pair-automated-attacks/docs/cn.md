# Red-Teaming：PAIR 和自动化攻击

> Chao, Robey, Dobriban, Hassani, Pappas, Wong（NeurIPS 2023，arXiv:2310.08419）。PAIR — Prompt Automatic Iterative Refinement（提示自动迭代优化）— 是经典的自动化黑盒越狱攻击。攻击者的 LLM 搭配红队系统提示，迭代生成针对目标 LLM 的越狱提示，将所有尝试和响应积累在自身聊天历史中，作为上下文反馈。PAIR 通常在 20 次查询内成功，相较于 GCG（Zou 等人的令牌级梯度搜索）效率高一个数量级，且无需白盒访问权限。PAIR 现已成为 JailbreakBench（arXiv:2404.01318）和 HarmBench 的标准基线，与 GCG、AutoDAN、TAP 和 Persuasive Adversarial Prompt（PAP）并列。

**类型：** 构建  
**语言：** Python（标准库，针对玩具目标的模拟 PAIR 循环）  
**先决条件：** 第18阶段·01（指令遵循），第14阶段（代理工程）  
**时间：** ~75 分钟

## 学习目标

- 描述 PAIR 算法：攻击者系统提示、迭代优化、上下文反馈。  
- 解释为何当目标是黑盒时，PAIR 明显比 GCG 更高效。  
- 列举另外四种自动化攻击基线（GCG、AutoDAN、TAP、PAP），并陈述各自一项区别特征。  
- 描述 JailbreakBench 和 HarmBench 的评估协议，以及在各自语境下“攻击成功率”的含义。

## 问题背景

红队测试曾是手工操作。少数专家测试者构造对抗性提示，并跟踪有效提示。这无法扩展：攻击成功率需要统计样本，而且每次模型发布，目标模型都会变化。PAIR 将红队测试转化为一个针对黑盒目标的优化问题。

## 核心概念

### PAIR 算法

输入：  
- 目标 LLM T（我们攻击的模型）。  
- 评判 LLM J（评估响应是否为越狱）。  
- 攻击者 LLM A（红队优化器）。  
- 目标字符串 G：“响应包含［有害指令］。”  
- 查询预算 K（通常为20次查询）。

循环，k 从 1 到 K：  
1. 用目标 G 和迄今为止的（提示，响应）历史提示攻击者 A。  
2. A 生成新提示 p_k。  
3. 将 p_k 提交给 T，获取响应 r_k。  
4. J 对 (p_k, r_k) 根据目标评分。  
5. 若分数 ≥ 阈值，停止——成功越狱。  
6. 否则，将 (p_k, r_k) 添加到 A 的历史，继续。

实证结果（NeurIPS 2023）：GPT-3.5-turbo、Llama-2-7B-chat 上攻击成功率超过50%；平均成功所需查询次数在10-20次。

### PAIR 高效的原因

GCG（Zou 等，2023）通过梯度搜索对抗性令牌后缀；它需要白盒访问，且生成不可读的后缀。PAIR 是黑盒攻击，生成自然语言攻击，可迁移至不同模型。PAIR 利用上下文反馈让攻击者从每次拒绝中学习；而 GCG 无此能力（每次令牌更新都需重新发现先前进展）。

### 相关自动化攻击

- **GCG（Zou 等，2023，arXiv:2307.15043）。** 对抗性令牌后缀的令牌级梯度搜索。白盒访问、可迁移、生成不可读字符串。  
- **AutoDAN（Liu 等，2023）。** 在分层目标指导下进行提示的进化搜索。  
- **TAP（Mehrotra 等，2024）。** 带剪枝的树状攻击——并行多个 PAIR 风格迭代。  
- **PAP（Zeng 等，2024）。** Persuasive Adversarial Prompts（有说服力的对抗性提示）— 将人类说服技巧编码为提示模板。

### JailbreakBench 和 HarmBench

两者（2024）标准化了评估流程：

- JailbreakBench（arXiv:2404.01318）。涵盖 10 类 OpenAI 政策类别中的 100 种有害行为。攻击成功率（ASR）为主要指标。需评判者（GPT-4-turbo、Llama Guard 或 StrongREJECT）。  
- HarmBench（Mazeika 等，2024）。覆盖 7 类共 510 种行为，包括语义和功能性危害测试。比较 18 种攻击对 33 个模型的表现。

ASR 通常在固定查询预算下报告。比较攻击时须匹配预算；比如 200 次查询下的 90% ASR 不可与 20 次查询下的 85% ASR 直接比较。

### 其对 2026 年部署的重要性

现今所有前沿实验室在发布生产模型前都会运行 PAIR 和 TAP。ASR 轨迹会呈现在模型卡（见第26课）和安全案例附录（见第18课）。此攻击非异类，而是标准基础设施。

### 在第18阶段的定位

第12课是自动化攻击基础。第13课（多轮越狱）是补充的长度利用。第14课（ASCII 艺术/视觉）是编码攻击。第15课（间接提示注入）是2026年生产环境的攻击面。第16课涵盖防御工具对应（Llama Guard、Garak、PyRIT）。

3. 阅读 Chao 等 2023 年第5图（PAIR 与 GCG 对比）。描述两个在 PAIR 更高效时仍倾向使用 GCG 的场景。

## 关键词

| 术语 | 常见说法 | 实际含义 |
|------|-----------------|------------------------|
| PAIR | “自动越狱” | Prompt Automatic Iterative Refinement；攻击者 LLM + 评判 LLM 循环 |
| GCG | “梯度越狱” | 令牌级别白盒梯度搜索对抗后缀 |
| 攻击成功率（ASR） | “k 次查询的%越狱成功率” | 主要指标；必须附带查询预算和评判者身份报告 |
| 评判 LLM | “评分器” | 判断响应是否满足有害目标的 LLM |
| JailbreakBench | “评估标准” | 标准化有害行为集合及类别标签 |
| HarmBench | “更广泛的基准” | 510 种行为，涵盖功能及语义危害测试 |
| TAP | “攻击树” | PAIR 的分支+剪枝版本；高计算下能提升 ASR |
