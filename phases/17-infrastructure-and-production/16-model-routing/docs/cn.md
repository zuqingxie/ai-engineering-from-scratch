# Model Routing 作为降低成本的原语

> 一个动态代理会评估每个请求（任务类型、token 长度、embedding 相似度、自信度），并将简单查询发送到廉价模型，将复杂查询升级到前沿模型。也称为模型级联（model cascading）。生产案例研究显示，在美国/英国/欧盟部署中，在等质量水平下能节约20-60%的成本；高流量SaaS中路由效率提升30%则转化为六位数的年度节省。2026 年背景是大语言模型（LLM）推理价格每年下降约10倍——从2022年底到2026年，一个 GPT-4级别的 token 从 $20/M 降到约 $0.40/M。大部分降价来自更优的服务堆栈（Phase 17 · 04-09），而非硬件。路由是如何将价格下降转化为利润而不牺牲产品质量的关键。失败模式是廉价模型漂移：路由将40%的流量推给能力较弱的模型，推理任务质量下降3-5%，一个季度内无人察觉。用在线质量指标作为路由门控，而非仅靠离线评测集。

**类型：** 学习  
**语言：** Python（标准库，玩具级级联路由器模拟器）  
**先修课程：** Phase 17 · 01（托管 LLM 平台），Phase 17 · 19（AI 网关）  
**时长：** 约60分钟

## 学习目标

- 解释模型级联：先用廉价模型，并以自信度检查，低自信时升级。
- 列举四个路由信号（任务分类、提示长度、与已知难例集的 embedding 相似度、首轮的自信度）。
- 计算目标路由分布和质量损失容忍度下的预计混合成本。
- 命名发现廉价模型漂移的监控指标（在线质量门控）。

## 问题描述

你的服务在 GPT-5 上花费每月8万美元。分析显示70%的查询很简单：“巴黎现在几点？”“重写这句话。”一个 Haiku级模型能用3%成本完美处理这类问题。30%的查询需要 GPT-5 的推理能力——编码、数学、多步规划。

如果你将70%的查询路由给廉价模型，30%给昂贵模型，账单会减少约65%，产品质量无变化。这就是路由。关键是构建代理时不降低质量。

## 概念

### 四个路由信号

1. **任务分类**：简单/复杂/代码生成/数学/聊天。可用规则分类器、小型 LLM（Haiku级，$0.25/M）或与标签桶的 embedding 相似度。输出路由命中：廉价 / 平衡 / 前沿。

2. **提示长度**：提示 >4K token 通常需前沿模型保证连贯性。<500 token 通常不需。

3. **与已知难例集的 embedding 相似度**：查询与难例桶余弦相似度 >0.88 时，直接升级到前沿。

4. **首轮自信度**：先送廉价模型；若模型输出概率(log-probs)低自信，或拒绝回答，或输出有保留表达，重试前沿模型。对约10%流量增加 P95 延迟，但对90%剩余流量节省50%以上。

### 三种模式

**预路由**（前置分类器）：增加5-10毫秒延迟；整体最快。

**级联**（廉价优先，低自信升级）：中位延迟约1.2倍（廉价计算+验证），升级流量约2倍延迟。质量底线最好。

**集成路由**（并行运行廉价和前沿做样本，基于奖励模型选优）：最高质量，成本最高；只用于关键 A/B 测试。

### 实现

AI 网关（Phase 17 · 19）公开路由接口。LiteLLM 提供 `router` 配置，带回退和成本路由。Portkey 有守卫和路由。Kong AI Gateway 具插件式路由。OpenRouter 的模型市场有推荐 API。

开源项目：RouteLLM（LMSYS）、Not Diamond（商业）、Prompt Mule。

### 2026 年价格曲线

| 模型等级 | 2022年底 | 2026年 | 变化 |
|---------|----------|--------|------|
| GPT-4级质量 | ~$20/M | ~$0.40/M | 降价50倍 |
| 前沿（GPT-5，Claude 4） | — | ~$3-10/M | 新价格等级 |

大部分改进源自服务效率 —— Phase 17 · 04-09 的核心经验转化为提供方成本下降。路由让你在应用层捕获这些收益，而不是等用户全部迁移到廉价层。

### 漂移是最大风险

路由将40%流量给廉价模型。六个月内，任务分布发生变化（用户变得更复杂，提问更长）。路由器不察觉，因为分类器基于第一季度数据训练。质量悄悄下滑。没人投诉。你最终在竞品基准测试中败下阵来。

用在线质量指标门控路由：

- 每条路由的用户点赞/差评率。
- 每条路由保留样本(5%)自动化 LLM 评议。
- 升级率：当级联升级比例超30%，说明廉价模型被过度路由。
- 每条路由拒绝率。

### 你应记住的数字

- 2026 年等质量下路由节省：20-60%案例。
- 2022-2026 年 LLM 价格下降：约每年10倍。
- GPT-4 级，2022 vs 2026：$20/M → $0.40/M。
- 级联延迟影响：中位 ~1.2倍，升级请求 ~2倍（约10%流量）。

1. 运行 `code/main.py`。级联在哪个准确度门限超过预路由？
2. 用户群30%企业（复杂查询），70%免费层（简单）。设计路由分配。用什么在线指标门控？
3. 某条路由质量下降2%，节约40%。是否可上线？视产品而定，请论证两种观点。
4. 用 OpenAI/Anthropic API 的 logprobs 实现自信度检查。你会从什么阈值开始？
5. 六个月内升级率从8%升至22%。诊断三种原因及对应改进。

## 关键词

| 术语 | 常见说法 | 实际含义 |
|------|---------|----------|
| Model routing | “成本代理” | 每请求动态选择模型 |
| Model cascade | “廉价优先升级” | 先跑廉价，低自信升级前沿 |
| Pre-route | “先分类” | 前置分类器，无重跑 |
| Ensemble route | “并行选择” | 多模型同时运行，奖励模型选最优 |
| Escalation rate | “升路百分比” | 级联中升级请求比例 |
| RouteLLM | “LMSYS 路由器” | 开源路由库 |
| Not Diamond | “商业路由器” | SaaS 模型路由产品 |
| Drift | “廉价模型漂移” | 分布变化，路由器未发现 |
| Online quality gate | “在线检查” | 自动 LLM 评议现场流量 |
