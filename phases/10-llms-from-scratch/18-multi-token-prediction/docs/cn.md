# 多标记预测（MTP）

> 从 GPT-2 到 Llama 3，所有自回归大型语言模型（LLM）都在每个位置上只训练一个损失：预测下一个标记。DeepSeek-V3 在每个位置上增加了第二个损失：预测再下一个标记。经过梯度流反向蒸馏，额外的 140 亿参数（基于 6710 亿参数模型）被整合回主模型中，训练好的 MTP 头部在推理时被重新用作具有 80%+ 接受率的猜测解码起草器。生成吞吐量提升了 1.8 倍且无额外代价。本课程根据 DeepSeek 技术报告搭建顺序 MTP 模块，计算损失与共享头部参数布局，并解释为什么 MTP 保持了因果链，而 Gloeckle 等人的原始并行 MTP 打破了它。

**类型：** 构建  
**语言：** Python（标准库）  
**前提条件：** 阶段 10 · 04（预训练一个迷你 GPT）、阶段 10 · 15（猜测解码）  
**时间：** ~60 分钟

## 学习目标

- 描述 MTP 训练目标并推导跨预测深度的联合损失。  
- 解释 Gloeckle 等人（2024 年）的并行 MTP 头部和 DeepSeek-V3 的顺序 MTP 模块的区别，以及为何顺序设计保留了因果链。  
- 计算在预训练过程中添加 MTP 模块的参数和内存开销。  
- 从零实现一个 MTP 模块：共享嵌入、各深度的 Transformer 块、投影和共享输出头。  

## 问题描述

下一个标记预测是标准的 LLM 训练目标。每个隐藏状态都被监督去预测一个精确的目标：紧接着的下一个标记。这个信号却非常弱。序列中的大多数信息超越了单个标记——结构、连贯性、事实性、算术流程。模型需要通过在万亿标记上累积大量单标记信号才能学到这些。

MTP 问：如果每个隐藏状态能同时监督预测多个未来的标记，会怎样？Gloeckle 等人（Meta，2024）证明了这确实有效。他们的实现是在主干后放置多个独立的输出头，每个头预测一个不同的偏移位置。并行设计简单，但所有头部共享相同隐藏状态，没有层级更新，而且预测之间无因果链，不能用于猜测解码。

DeepSeek-V3（2024 年 12 月）重新设计了 MTP，作为顺序模块，在每个预测深度都保留因果链。模型先用 `h_i^(0)` 预测 `t+1`，再用新的隐藏状态 `h_i^(1)`（结合了 `h_i^(0)` 和 `E(t+1)` 嵌入）预测 `t+2`，依此类推。每个深度是一个小 Transformer 块。共享嵌入和共享输出头将参数开销保持在合理范围内。DeepSeek-V3 级别下，MTP 模块上的额外参数量为 140 亿（相对于 6710 亿主模型权重），约 2% 开销，换来了更丰富的训练信号和推理时现成的猜测解码草稿。

本课程将从头构建单个 MTP 模块和 D 深度损失。数学推导简洁，代码实现约 150 行。

## 概念解释

### 顺序 MTP 配方

DeepSeek-V3 在主模型之上添加了 `D` 个 MTP 模块。每个模块 `k`（`k=1..D`）负责预测深度为 `k` 的标记，即在给定前缀到位置 `i` 的条件下预测 `t_{i+k}`。

模块 `k` 由以下部分组成：

- 一个具有独立注意力和多层感知机（MLP）的 Transformer 块 `T_k`。  
- 一个投影矩阵 `M_k`，将前一深度的隐藏状态与下一深度真实标记的嵌入结合起来。  
- 共享嵌入 `E`（与主模型相同）。  
- 共享输出头 `Out`（与主模型相同）。  

训练时，针对给定位置 `i` 的前缀，各深度隐藏状态为：

```text
h_i^(0) = 主模型主干在位置 i 的隐藏状态
h_i^(k) = T_k( M_k * concat(RMSNorm(h_i^(k-1)), RMSNorm(E(t_{i+k}))) )   对 k >= 1
```

各深度的预测为：

```text
logits_{i+k} = Out(h_i^(k-1))   对 k = 1..D
```

每个深度的损失为交叉熵，针对真实标记 `t_{i+k}`：

```text
L_k = CE(logits_{i+k}, t_{i+k})
```

跨深度的联合损失为：

```text
L_MTP = (lambda / D) * sum_{k=1..D} L_k
```

`lambda` 是一个小的加权因子——DeepSeek-V3 在训练的前 10% 期间使用 0.3，之后使用 0.1。总训练损失为 `L_main + L_MTP`。

### 为什么要顺序而非并行

Gloeckle 的原始并行 MTP 有 D 个输出头，全部直接作用于 `h_i^(0)`。每个头从相同主干隐藏状态预测不同偏移的标记。这种训练是可行的，但预测之间没有条件依赖。你不能用第 1 个头的输出来帮助第 2 个头，头部并行工作。

DeepSeek-V3 的顺序设计通过在生成 `h_i^(k)` 时利用 `h_i^(k-1)` 和真实的下一标记嵌入 `E(t_{i+k})`，保留了因果链：预测 `t_{i+k+1}` 时，深度 `k+1` 的模块能看到 `t_{i+k}` 的信息。这在结构上等价于自回归解码器自身输出的消费方式——使 MTP 模块可直接用作猜测解码起草器。

推理时：将 `h_i^(k-1)` 和草拟的 `t_{i+k}` 送入模块 `k+1`，得到对 `t_{i+k+1}` 的预测，循环往复。这正是 EAGLE 风格的草稿，训练好的 MTP 模块作为草稿网络。DeepSeek-V3 报告第一个 MTP 模块接受率超过 80%，速度提升约 1.8 倍。

### 参数统计

假设模型隐藏维度为 `h`，词汇大小为 `V`：

- 主模型：拥有数十亿参数，另加一个大小为 `V * h` 的输出头。  
- 共享输出头：重复利用主模型的输出头，无额外参数。  
- 共享嵌入：复用主模型的嵌入，无额外参数。  
- 每个 MTP 模块包括：  
  - 投影矩阵 `M_k`：大小 `(2h) * h = 2h^2`。  
  - Transformer 块 `T_k`：包含多头注意力（MHA，大约 `4h^2`）和 MLP（通常为 SwiGLU，比例约 8/3，约 `8h^2`）。每个块约 `12h^2`。  

每个模块额外参数总计约 `~14h^2`。以 DeepSeek-V3 的 `h = 7168`，且 `D=1` 模块为例，计算得 `~14 * 7168^2 = ~7.2亿` 参数。DeepSeek-V3 报告是 140 亿，差异主要来自 MTP 模块中采用的专家层 MoE 结构。

### 猜测解码的收益

在预训练期间，MTP 模块使训练变慢约 10%（更多的前向计算，额外的损失）。收益体现在两方面：

1. 更丰富的训练信号。每个隐藏状态接收 `D+1` 个监督目标。在 DeepSeek-V3 的消融实验中，对 MMLU、GSM8K、MATH、HumanEval 等指标都有稳定数个百分点的提升。  

2. 推理时免费获得猜测解码草稿。MTP 模块已训练好预测接下来若干标记。用作草稿网络，实现超过 80% 的接受率。在该接受率水平下，N=3 或 N=5 的猜测解码能带来约 1.8 倍的吞吐量。训练时间的 10% 额外开销第一次推理时就回本。

### 与 EAGLE 的关系

EAGLE 在预训练结束后独立训练一个小型草稿模型。MTP 将草稿训练直接嵌入预训练过程。两者在接受率上较为接近，但实现路径不同：

| 维度               | EAGLE-3         | MTP（DeepSeek-V3）       |
|--------------------|-----------------|--------------------------|
| 训练时间           | 预训练后         | 预训练期间               |
| 向后兼容现有权重     | 是              | 否（需重新训练）          |
| 草稿参数           | 1-2 层 Transformer | 1 个 Transformer 块 + 投影 |
| 接受率             | 0.88-0.92       | 深度 1: 0.80+            |
| 除加速外的益处       | 仅猜测解码       | 更密集训练信号 + 加速      |

## 构建它

`code/main.py` 从端到端构建单个 MTP 模块：共享嵌入、投影、Transformer 块、共享输出头。然后对一个简短的合成序列计算各深度交叉熵损失，并打印各组件的参数计数。32 个标记的玩具词汇使数字易于理解。

### 步骤 1：共享嵌入表

一张大小为 `vocab_size x hidden` 的表由主模型和每个 MTP 模块的每个深度共用。同一张张量，不复制。

### 步骤 2：各深度组合

```python
def combine(prev_hidden, next_token_embed, M_k):
    # 在特征维度拼接，然后投影回隐藏维度
    concat = rms_norm(prev_hidden) + rms_norm(next_token_embed)  # 用向量加法简化实现
    projected = matvec(M_k, concat)
    return projected
```

真实的 DeepSeek-V3 是将两个 RMSNorm 后的向量拼接成 `[2h]` 维度后，用 `h x 2h` 矩阵投影。玩具实现为了简洁用向量相加代替。

### 步骤 3：深度 k 的 Transformer 块

包含自注意力和 MLP。玩具版本用一层线性注意力块和 SwiGLU MLP，结构简洁而无须 numpy。

### 步骤 4：共享输出头

复用主模型的输出投影，将隐藏状态映射到词汇表 logits。

### 步骤 5：各深度损失

对 softmax(logits) 与真实偏移 `k` 标记做交叉熵损失，使用 `lambda / D` 缩放后跨深度累加。

### 步骤 6：参数统计

打印总参数量、共享参数量（嵌入和头部）和每模块额外参数量。展示 MTP 额外参数与主模型大小的比例。

## 使用它

MTP 集成在 DeepSeek-V3（2024 年 12 月）和 DeepSeek-R1 系列中。推理时：

- DeepSeek 自有服务栈开箱即用地将 MTP 模块作为猜测解码器。  
- 截至 2026 年 4 月，vLLM 和 SGLang 已集成 DeepSeek-V3 MTP。  
- AMD 的 ROCm SGLang 教程展示了具体的 MTP 猜测解码配置，并在 V3 检查点上实测获得了 1.8 倍加速。  

何时在新的预训练中使用 MTP：

- 你掌控完整预训练流程，想要积累更丰富的训练信号。  
- 计划大规模部署模型，想无额外代价获得猜测解码。  
- 模型隐藏维度至少 4096，1B 级规模时额外开销可能超过收益。  

何时不宜：

- 对已有预训练密集模型微调，MTP 模块未训练。  
- 需要干净基线做研究对比的模型，MTP 会改变架构。

## 练习

1. 运行 `code/main.py`。观察随着合成信号加强，各深度损失单调下降。修改合成模式为固定模式，验证深度 1 和深度 2 的损失均收敛。  

2. 计算一个 700 亿密集模型（隐藏 8192，80 层）带 `D=1` MTP 模块的参数开销。与 DeepSeek-V3 报告的 140 亿参数开销比对。解释 DeepSeek 数值偏高的原因：MTP Transformer 块继承了 MoE 结构，膨胀了参数。  

3. 在玩具模型中实现 `D=2`：增加第二个 MTP 模块，接受 `h^(1)` 并预测 `t_{i+2}`。验证联合损失和参数统计是否符合 DeepSeek 论文式 19-21。  

4. 将玩具模型切换为并行 MTP（Gloeckle 风格）：在主隐藏状态上加入 D 个输出头，各预测不同偏移。比较与顺序版本在相同合成信号下的各深度损失。顺序版本应在 `k > 1` 时损失更低，因为它条件于中间预测。

5. 使用训练好的 MTP module 作为 EAGLE 风格的草稿：在推理时调用模块 k 来提议 `t_{i+k}`。在保留的序列上测量这些草稿 token 相对于主模型预测的接受率。如果你在玩具数据上达到 50% 以上，就复现了经验性的 MTP 作为草稿的特性。

## 关键词

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| MTP module | “额外损失块” | 一个小型 Transformer（Transformer 架构）模块加映射层，预测主模型前方 `k` 个位置的 token |
| Prediction depth | “哪个偏移” | 整数 `k`，表示模块 `k` 在通过位置 `i` 的前缀基础上预测 `t_{i+k}` |
| Parallel MTP | “Gloeckle 风格” | 在相同 backbone（主干）隐藏状态上有 D 个独立头部，没有条件链 |
| Sequential MTP | “DeepSeek-V3 风格” | 每个模块基于前一深度的隐藏状态加上下一个 token 的嵌入向量进行条件建模；保留因果链 |
| Shared output head | “复用主头” | MTP 模块调用主模型的语言模型（Language Model, LM）头部，而非单独的输出映射 |
| Shared embedding | “复用主词表” | 整个模型使用相同的词汇嵌入表；没有重复参数 |
| Projection matrix M_k | “结合隐藏状态 + 下一个 token” | 一个 `h x 2h` 线性层，将先前隐藏状态和目标 token 嵌入折叠为下一深度的输入 |
| Joint loss L_MTP | “平均额外损失” | 每个深度交叉熵损失的算术平均，乘以比例系数 `lambda` |
| Acceptance rate at depth 1 | “MTP 草稿正确率” | 当 D=1 时 MTP 模块的 top-1 预测与主模型 top-1 预测相等的频率；DeepSeek-V3 上超过 80% |
| Lambda weighting | “额外损失权重” | 每个深度的缩放因子；训练开始时为 0.3，DeepSeek-V3 后期为 0.1 |
